# 過去のループデッキ調査(闇系中心)

Web検索で確認した実在ループの構造分解と、本シミュレーターのループ原語マッピング。
ループ探索器(不動点検出)の設計基礎資料。

## 実在した闇系ループの系譜

### 1. サガループ(水闇, 2023年・本家)
- **核**: 《絶望神サガ》×2枚のみで自己完結する相互蘇生ループ
- **サイクル**: サガA着地 →(出た時)墓地のサガBを蘇生(コスト5以下)→ 自分のクリーチャー1体破壊(A自壊)→ サガB着地 →(出た時)墓地のAを蘇生 → …
- **収支**: 「出た時」誘発を無限に発生させ、付随ドロー・墓地肥やしで山札を掘り切り任意のフィニッシャーへ。最速3ターン
- **結末**: 殿堂入り。歴代最強級ループとの評価

### 2. オカルトアンダケイン(闇単中心, 2020年・本家)
- **核**: 《不敵怪人アンダケイン》(フシギバース=場のクリーチャーをコストにして墓地から召喚)+《フォーエバー・オカルト》
- **サイクル**: 場のクリーチャーをコスト化→墓地から再展開→《フォール・クロウラー》(相手マナ送り)《ラビリピト》(全ハンデス)を使い回し
- **収支**: 相手のマナと手札を毎周削り、最終的にライブラリアウト
- **結末**: 2021年7月、アンダケイン等の殿堂入りで終焉

### 3. MRCロマノフループ(闇/赤黒, DMR期・本家+デュエプレ実装)
- **核**: 《M・R・C・ロマノフ》(攻撃時、墓地の呪文を3枚まで唱え、唱えた呪文を山札の下へ)+蘇生呪文セット(《インフェルノ・サイン》《法と契約の秤》等)
- **サイクル**: 墓地呪文3枚発射→呪文は山札下へ戻る(=弾の再装填)→蘇生で2体目のMRC/ロマノフⅡ世→再攻撃→無限蘇生で《ガジラビュート》(シールド焼却)・《学校男》(自壊除去)を無限回着地
- **収支**: シールド全焼却+盤面全壊からのワンショット

### 4. ヴォルグ・サンダーLO/ザビミラ型(闇+水自然, 2011年頃・本家+デュエプレ)
- **核**: 《復活の祈祷師ザビ・ミラ》(自分クリーチャーをサイキックに変換)+《ヴォルグ・サンダー》(出た時、相手山札からクリーチャー2枚が落ちるまで墓地送り)
- **サイクル**: 厳密な無限ループではなく「大量変換による一斉山札破壊」
- **結末**: ヴォルグは本家でプレミアム殿堂。**デュエプレでも環境入りし運営調整が入った=デュエプレ史の代表的な闇系疑似ループ**

### 5. 無限死神/ヒドラ系(闇, 最古典・本家)
- **核**: 《凶星王ダーク・ヒドラ》(種族クリーチャーの墓地回収)+《死神術士デスマーチ》等の軽量墓地進化・自壊
- **サイクル**: 自壊→ヒドラで回収→再展開、の半永久リソースエンジン
- **位置づけ**: 「歴代名作デッキ」に数えられるループの祖型

### デュエプレ特有の注意
デジタル実装のデュエプレでは無限ループはクライアント側で回数制限・カード調整(ナーフ)
の対象になる。研究上は「無限」ではなく**「1ターン内の大量反復(有限ループ)」**として
モデル化するのが正しい。

## ループ原語マッピング(本シミュレーターとの対応)

| ループ型 | 必要な原語 | 現状 |
|---|---|---|
| **サガ型(相互蘇生)** | summon_from_grave + 自壊(destroy scope self) + 出た時の再帰発火 | **すべて実装済み**。表現・検出が現エンジンの射程内 |
| ヒドラ型(回収エンジン) | grave_to_hand + 自壊 + 再召喚 | ほぼ実装済み(種族条件は近似) |
| MRC型(呪文再装填) | cast_from_grave + 唱えた呪文の山札下戻し | 未実装(cast_from_grave op が必要) |
| アンダケイン型(フシギバース) | 場のクリーチャーをコスト化する代替召喚 + 置換効果 | 未実装(コスト変換・置換効果) |
| ザビミラ型(超次元変換) | 超次元ゾーン | 未実装 |

**重要な含意**: 史上最強級とされるサガ型の構造(A出た時→B蘇生→自壊、Bも同様)は、
summon_from_grave・scope self破壊・再帰実行(深さ5)を実装済みの現エンジンで
**既に表現可能**。ループ探索器の第一弾は「相互蘇生対の静的検出
(AのEffectScriptがBを蘇生でき、BがAを蘇生できる組)+収支検証」から始められる。

## ループ探索器の設計方針(次フェーズ)

1. **静的スクリーニング**: 承認済みEffectScriptから「蘇生/回収/踏み倒しを持つカード対」を列挙し、
   相互到達(A→B→A)とコスト収支(蘇生上限≧相手のコスト)を機械判定
2. **動的検証**: 候補対を一人回しに投入し、1ターン内の反復回数を計測
   (回数が深さ上限に張り付く=ループ成立のシグナル)
3. **デュエプレ準拠**: 反復上限付きの「有限大量ループ」として評価(無限判定はしない)

## ループ探索器・第一弾の実行結果(2026-06)

`python -m src.battle.research loop-find` を実装・実行した。

- **検出能力の証明**: サガ構造(自壊→自己蘇生)の合成カードを反復上限到達として
  正しく検出し、自壊なしの単純蘇生は有限(墓地コピー数で停止)と正しく区別する
  (tests/test_loop_finder.py)。
- **実プールでの結果**: 静的候補556件、上位の「ループ署名」(阿修羅サソリムカデ、
  偽りの名 ドレッド・ブラッド、ジグス★ガルビ等)を原文照合した結果、
  **すべて近似由来の偽陽性**だった:
  - 阿修羅サソリムカデ: 原文は「自身以外・マフィ・ギャング限定」の蘇生+
    「ターン終了時」破壊 → 変換で3制約とも欠落
  - ジグス★ガルビ: 「無月の門を使った時」の条件付き誘発 → 無条件on_playに誤変換
  - ドレッド・ブラッド: 「ターン開始時、墓地にあれば」 → on_playに誤変換
- **結論**: 「ループは近似に殺される/近似はループを捏造する」の両面が実証された。
  探索器は完成しており、ボトルネックは世界モデルの精度。偽陽性リストが
  そのまま精密化の作業リスト:
  1. 蘇生の「自身以外」フラグ(exclude_self)
  2. 種族フィルタ(race)
  3. 「ターン終了時」タイミング(現状は即時破壊に近似)
  4. 条件付き誘発(無月の門・ターン開始時等)を変換不可として下書きに残す
     (誤って無条件承認しない)精度ゲートの強化


## 第二弾: 忠実度ゲート導入とexact限定再走の結果(2026-06)

偽陽性4点セットへの対策を実装した:
- `fidelity` 列(exact/approx)を card_effects に追加。**自動下書きは常にapprox**、
  exactはキュレーションで明示した場合のみ。`load_approved_effects_map(exact_only=True)`
  でループ探索は精密集合だけを見る
- 精密パラメータ: `summon_from_grave` に exclude_self / exclude_evolution / race、
  `destroy_creature` に timing="end_of_turn"(遅延破壊キュー)を追加
- ループ関連カード11種を原文照合してexactキュレーション
  (`data/effect_scripts/curated_loops_exact.json`)。条件付き能力(無月の門・
  ターン開始時・種族条件)は**表現できないものを省略=過小評価側に倒す(exact-safe)**

**exact限定 loop-find の結果: 静的候補0件。**

結論: 精密にモデル化した範囲において、現デュエプレプールに
サガ型(無条件の相互/自己蘇生)ループは存在しない。クリーチャーの自己蘇生は
すべて「無月の門」等の条件ゲート付きであり、これは実ゲームの制約とも一致する。
ループへの残された道は: (1) 条件付き誘発のモデル化(無月の門=魔導具メカニズム)、
(2) MRC型(cast_from_grave)の実装、(3) exactキュレーションの対象拡大。
偽陽性ゼロの探索基盤は完成しており、今後exact集合を広げるたびに
この問いへの答えが自動更新される。

既知のデータ課題: cards.race列が空(種族データ欠落)のため、
種族限定蘇生(マフィ・ギャング等)はexact表現不可。取り込み側の修正が必要。


## 第三弾: MRC型エンジンの実装と歴史的ループの初再現(2026-06)

`cast_from_grave` op(墓地の呪文を無償詠唱→山札の一番下へ)と、蘇生への
SA付与(`speed_attacker`)・文明フィルタ・「相手が選ぶ」破壊(`chooser`)を実装。
プールに実在するMRC型の部品(邪眼大帝 ラスト・ロマノフ/暗黒GUY・ゼロ・ロマノフ/
煉獄と魔弾の印/冥府の覇者ガジラビュート/学校男/法と契約の秤)を原文どおり
exactキュレーションした。

**再現実験(史実盤面: ゼロ・ロマノフ1体+墓地に印3・ガジラビュート2・ゼロ1)**:

```
ゼロ#1攻撃 → 印を墓地詠唱 → ゼロ#2をSA付き蘇生 → #1がシールド2枚ブレイク
ゼロ#2攻撃 → 印を墓地詠唱 → ガジラビュート蘇生(シールド1枚焼却) → #2が2枚ブレイク
ガジラビュート(SA)がダイレクトアタック → 1ターンで勝利
```

**歴史上のMRCワンショットが、精密スクリプトのみで初めてシミュレーター内に再現された。**
ループ探索器の「陰性」(サガ型は現プールに不在)に続き、「陽性」方向の能力
(実在エンジンを正しく回せる)も実証されたことになる。回帰テスト化済み
(tests/test_loop_finder.py::MRCEngineReproductionTest)。

実装中に発見・修正したデータ起因バグ: 多色表記が「闇火」(区切りなし)のカードがあり、
文明フィルタの完全一致が失敗していた→部分一致に修正。

次: loop-find の静的スクリーニングに「呪文再装填型」(on_attack cast_from_grave ↔
蘇生呪文の往復)の検出を追加すれば、MRC族の網羅列挙が可能になる。


## 第四弾: 呪文再装填型の自動検出(2026-06)

loop-find の静的スクリーニングに「呪文再装填型」を追加した:
攻撃時詠唱エンジンE(on_attack cast_from_grave)と、Eを蘇生できる呪文S
(on_cast summon_from_grave)の往復成立を機械判定し、SのSA付与有無で
「ワンショット候補/持続型」に分類。動的検証はエンジン1体+墓地(S4・E3)から
攻撃フェイズを実走し、詠唱・蘇生回数と1ターンキル成立を計測する。

**exact限定での実行結果**:

```
[ワンショット候補] 暗黒GUY・ゼロ・ロマノフ + 煉獄と魔弾の印
  → ★1ターンキル(詠唱4回・シールド5枚)を自動検出
[持続型] ゼロ・ロマノフ + インフェルノ・サイン → 蘇生1回(SA無しのため跨ターン型)
```

人手で再現した前章のMRCワンショットを、**探索器が静的列挙→動的証明まで全自動で
到達できる**ことを確認した。exactキュレーションを増やすほど、この網に
未知のエンジン対が掛かる体制が完成した。

ループ探索器の対応族: サガ型(相互/自己蘇生)・ヒドラ型(回収)・呪文再装填型(MRC族)。
未対応: フシギバース型(置換効果)・超次元型。


## 第五弾: 網の拡大と【ロマノフサイン】の自律的再発見(2026-06)

プール全体から「攻撃時詠唱」を持つカードと無条件蘇生呪文を機械抽出し、
無条件のもの4種(邪眼皇ロマノフI世/狂気と凶器の墓場/戒王の封/魔法特区 クジルマギカ)を
exactキュレーションに追加した(計21種)。再走結果:

```
[ワンショット] 暗黒GUY・ゼロ・ロマノフ + 煉獄と魔弾の印 → ★1ターンキル(既知)
[ワンショット] 邪眼皇ロマノフI世 + 煉獄と魔弾の印 → ★1ターンキル(新検出)
[持続型] ラスト・ロマノフ × 戒王の封 / ゼロ・ロマノフ × 戒王の封・サイン(新検出)
```

**「ロマノフI世+印」は組み合わせを人間が指定したものではなく、個々のカードを
原文どおりexact化しただけで探索器が自力で対にし、1ターンキルを証明した。**
この対は本家で実在した名デッキ【ロマノフサイン】の核そのものであり、
コンボ発掘(デ・スザーク骨格)・役割探索(ボルコン/連ドラ)に続き、
**ループ探索の階層でも歴史的収束が起きた**。

体制の現状: exactキュレーション1枚追加ごとに、既存の全exactカードとの
エンジン対が自動照合される。「人間がまだ気づいていない対」が掛かる条件は
(1) 部品が現プールに存在し、(2) 無条件(または将来、条件モデル化済み)であること。


## 第六弾: 【黒単ロマノフサイン・再誕】のデッキ化とメタ判定(2026-06)

自律発見したエンジン対を核に、全40枚がexactスクリプト済みの黒単デッキを構築した
(generated_decks id=20、カタログ掲載済み)。エンジン: ロマノフI世4+印4を軸に、
肥やし(ヴォジャワ/墓場/ラスト・ロマノフ)、蘇生(サイン/戒王の封)、
焼却(ガジラビュート)、ルーター(ソー☆ギョッ)。

**メタ判定: 絶対強さ43.6**(対スコーラー68%・対火光58%だが、自己対戦アグロ群に17〜29%)。
エンジンは組めれば1ターンキル(証明済み)だが、組み上がりの数ターンを速攻に
咎められる——**史実のロマノフサインが持っていた強みと弱みの両方が再現された**。
試合時間も平均15〜21ターンとコンボらしい長さ。

改善余地: 方策がエンジン組立(ロマノフ着地→攻撃)を優先しない、
ソー☆ギョッの捨て札がランダム(本来はロマノフ/印を選んで捨てたい)。
コンボ方策のMRC型対応(エンジン優先の行動規則)が次の伸びしろ。


## 第七弾: コンボ方策のMRC型対応——アブレーションが暴いた「保護しすぎ」の罠(2026-06)

前章の改善余地「捨て札の選択・エンジンのチャージ保護」を方策に実装した。
Policy基底に `choose_discard` フックを追加し、実行器の `discard_own_hand` が
コントローラーの方策に捨て札を問い合わせる(Noneならランダムにフォールバック)。
ComboPolicyは `bind()` で効果マップからエンジン(on_attack cast_from_grave)と
蘇生呪文(on_cast summon_from_grave)を抽出し、墓地適性カードを選んで捨てる。

**第一版は大失敗だった。** 墓地適性カード全体(エンジン+蘇生呪文=デッキの半分)を
マナチャージから保護したところ、id=20の強さは43.0→**29.4**へ暴落。
要因分解(各100試合×8相手、同一シード):

| 方策 | 強さ |
|------|------|
| Greedy(基準) | 43.0 |
| Combo(G・ゼロのみ) | 43.0 |
| 選択捨てのみ | 41.2 |
| チャージ保護のみ(全墓地適性) | **28.4** |
| 保護をエンジン限定+全保護時は貪欲退避 | **45.8** |

主犯はチャージ保護の**選択効果**: 保護されないカードから順にマナへ消え、
手札は保護カードだけになり、以後チャージ不能→マナが4〜5で永久に止まり
蘇生呪文(コスト5〜7)を唱えられない。「墓地に置きたい」と「マナが要る」は
同じ資源を奪い合うため、保護は希少部品(エンジン本体6枚)に絞り、
手札が保護対象のみになったら貪欲に退避するのが正解だった。

**最終形: 43.0→45.8(+2.8)**。内訳は自己対戦アグロ群への耐性改善が大きい
(R1: 20→28% / R2: 37→48% / R3: 19→26%、デンジャデオン57→64%)。
エンジンが手札に温存され、サインからの蘇生が安定したことで
中速相手の捲り合いに強くなった。実装はテスト153件で固定済み
(選択捨て・エンジン保護・全保護時退避・実行器の方策問い合わせ)。

教訓: **コンボ方策の規則は1つずつ計測して入れる。**「良さそうな規則」の
複合は、要因分解しなければ29.4のまま「MRC対応は逆効果」と誤結論していた。
測定スクリプトは scripts/measure_combo_mrc.py に保存。


## 第八弾: エンジン組立規則と「方策込みレーティング」(2026-06)

第七弾の教訓(規則は1つずつ計測)に従い、エンジン組立の行動規則2つを
個別にアブレーションした(id=20、各100試合×8相手、同一シード、基準45.8):

| 規則 | 強さ | 採否 |
|------|------|------|
| 蘇生呪文優先(墓地にエンジンがあれば召喚より先に唱える) | **47.5** | 採用 |
| エンジン先制攻撃(攻撃時詠唱の連鎖を狙って先に殴る) | **40.8** | 不採用 |
| 両方 | 42.1 | — |

蘇生呪文優先が効くのは、貪欲方策が「クリーチャー優先」のため蘇生呪文を
後回しにし、エンジンが墓地に眠ったままになっていたから。一方の先制攻撃は、
貪欲の「勝てるクリーチャー戦を先に取る」判断を上書きしてしまい、
有利交換を捨ててブロッカーや除去に突っ込むぶん大きく損をした。
直感的に「コンボ的に正しい」規則でも、計測なしでは採用できない好例が続いた。

**累計: Greedy 43.0 → MRC対応コンボ方策 47.5(+4.5)**。

あわせて `rate_deck_against_meta` に `policy_factory` 引数を追加し、
CLIの `--policy` が rate / rate-generated にも効くようにした:

```bash
python -m src.battle.research --policy combo rate-generated --id 20
```

これまでの絶対強さスコアは全てGreedy操作の値であり、コンボデッキは
**操作方策の分だけ過小評価されていた**(本デッキで4.5pt)。今後コンボ系の
生成デッキを評価するときは `--policy combo` の値を併記すること。
相手側は比較可能性のため常にGreedyで固定している。


## 第九弾: MRC核をロックした進化探索——「コンボは荷物になった」(2026-06)

MRC対応方策が世代選別(両側コンボ方策)と最終判定(--policy combo)の両方に
入った初の条件で、id=20をシードに進化探索を実行した:

```bash
python -m src.battle.research --games 100 --seed 31 --policy combo \
  hybrid-search --generations 12 --population 14 \
  --civilizations 闇,火,水,無色 --seed-deck-id 20 \
  --lock "邪眼皇ロマノフI世,煉獄と魔弾の印"
```

結果は **絶対強さ61.3**(id=21【黒赤ロマノフ・ブリッツ】、別シード再測定で65.1)。
手組みのid=20(コンボ方策47.5)を大きく超えた——が、中身を検証すると
進化は予想と違うことをしていた。

**進化は墓地肥やしを全廃した。** ヴォジャワ/狂気と凶器の墓場/サイン/ソー☆ギョッは
1枚も残らず、シェルは2〜3コストの黒赤アグロ(ザビフライ/ダチッコ・チュリス/
ブッチビーズ等)に置き換わった。効果ログを数えると、ロックした
エンジンの発火は**3〜6/50試合**(ロマノフは57回詠唱を試みるが墓地に呪文がない)。
61.3の出どころはテンポであり、ロマノフ4+印4はほぼ「8枚の荷物」だった。

蘇生呪文の発動条件を一般化した方策(墓地に蘇生対象がいれば印を唱える)も
試したが、発火は2倍(6/50)になるものの強さは65.1→65.5で誤差内。不採用とし、
試作は scripts/measure_combo_mrc.py の ComboReviveValue に残した。

**知見: 選別圧はコンボを強化しない。コンボを荷物にしたまま勝てるシェルを選ぶ。**
MRCエンジンは「肥やしに数ターン投資して初めて回る」構造のため、
その投資はこのメタ(速攻が上位)ではテンポ負けとして即座に罰される。
史実でMRCが専用構築(全カードを墓地戦略に捧げる)だったことと整合する:
**コンボデッキは部分採用が利かず、全振りか不採用かの二択**になる。
未開拓コンボを探索で発掘するには、ロックだけでは足りず、
「エンジン発火率」を選別関数に組み込む必要がある(chain成立率と同じ構図)。


## 第十弾: 発火圧付き進化——進化がエンジン一式を自力で再構築した(2026-06)

第九弾の対策として、選別関数に「エンジン発火率(墓地詠唱・蘇生が成立した
試合の割合)」を組み込んだ(`hybrid-search --engine-weight`)。カーネルが
効果成立をログと無関係に常時カウントするため、選別コストは増えない。

第九弾と完全同条件(id=20シード、ロマノフI世+印ロック、12世代、同シード)に
`--engine-weight 0.25` だけを加えた対照実験の結果(強さ/発火率は
コンボ方策・各100試合×8相手・同一シードで再測定):

| デッキ | 強さ | 発火率 | 備考 |
|--------|------|--------|------|
| id=20 黒単ロマノフサイン・再誕(手組み) | 47.5 | 61.9% | 全カードexact |
| id=21 黒赤ロマノフ・ブリッツ(発火圧なし) | 65.1 | 2.4% | コンボは荷物 |
| id=22 邪眼転生ロマノフサイン(発火圧0.25) | **59.1** | **75.5%** | **両立** |

id=22は手組みのid=20を**強さ(+11.6)と発火率(+13.6pp)の両軸で上回った**。
進化の中身が雄弁で、発火圧は墓地肥やし一式(ソー☆ギョッ4/ヴォジャワ4/
墓場4/サイン4/印4/戒王3)を**淘汰から守るどころか自力で復元**し、
フィニッシャー枠をガジラビュート2+バルクライ王2+XENOM2+デ・スザーク2へ
組み替えた。バルクライ王は史実のロマノフ系デッキの実在の相棒だが、
シミュ上はバニラ扱い(進化条件が未対応)なので「正しいカードを別の理由
(打点)で選んだ」点は割り引いて読むこと。

発火元の内訳(120試合): ロマノフ223回/墓場87/サイン73/印62/戒王41が
exactスクリプト由来で全体の97.4%。approxスクリプトを持つデ・スザークの
寄与は13回(2.6%)に留まり、発火率は捏造ではない。

**結論: コンボデッキの探索は「ロック+発火圧」で初めて閉じる。**
ロックは骨格を守るが進化はそれを荷物にする(第九弾)。発火率を適応度に
入れると、進化は「勝ちながら回る」均衡点を自分で見つける。強さの代償は
6pt(65.1→59.1)であり、これが現メタにおける「コンボを回すことの価格」の
定量値になった。次の応用: combo-mine の --evolve にも engine_weight を
渡せば、未知のエンジン対の発掘→デッキ化まで全自動で同じ品質が出るはず。


## 第十一弾: 全自動パイプラインと三つの捏造事件——進化は最強のファザーである(2026-06)

combo-mine --evolve に発火圧を接続し「発掘→動的証明→発火圧付きデッキ化」を
全自動化した。その実走が、シミュレータの誤読を立て続けに暴いた。

**事件1: 父なる大地(id=23, 偽の強さ77.0)。** 原文「相手のマナゾーンから選び、
相手はこれをバトルゾーンに出す」(妨害)を、approxスクリプトがscope欠落で
「自分のマナから踏み倒す」と誤読。進化はコスト51のギュウジン丸をマナに
チャージ→誤読の父なる大地で4ターン目に着地、という捏造コンボを最適化した。
→ summon_from_manaにscope/exclude_evolution実装、父なる大地をexact化、
combo-mineの提案をexact限定にゲート(loop-findと同じ忠実度ゲート)。

**事件2(修正中に発覚): 幻の0%と死にコード。** exact限定にすると全チェーンが
成立率0%に。原因は2つ: (a)打点持ちツインパクトはクリーチャーとしてプレイ
されるため呪文面のon_castはカーネルで発火しない死にコード(デーケン/ルソーを
環とする提案は全て幻)、(b)goldfishのチャージ規則「出せない最高コスト」が
チェーンの環(中〜高コスト)を系統的にマナへ沈めていた。
→ 提案の環は「実際に発火するトリガー」のみから抽出、検証器はチェーン部品を
チャージから保護(パイロットの意図の再現)。修正後は35〜38%の妥当な成立率。

**事件3: ストーム・クロウラー(id=24, 偽の強さ72.5)。** 再走の成果の発火率
85.6%を検証すると、発火の90%が「マナから1枚を手札に戻す」を
summon_from_manaと誤読したapproxスクリプト由来だった。下書き生成器の
「バトルゾーンに出」が「出た時」のトリガー句に誤反応していたのが根因。
→ regexを他動詞「出す/出し」に限定し、自動承認1,626件をdraft降格→全再生成→
再承認。さらに**発火指標の発生源をexactスクリプトに限定**(fire_source_ids)し、
approxが指標を荒稼ぎする構造自体を遮断した。

**正本の成果: id=25【黒単戒王リアニメイト】強さ52.8(標準条件55.0)、
chain成立率36.7%、exact発火率15.2%、発火源は戒王の封のみ=捏造ゼロ。**
ヴォジャワ肥やし→戒王の封→アマデウス/ヴィオラ・ソナタという、実ルールで
本当に回るリアニメイトデッキを全自動で発掘・構築できた。なお誠実な指標では
進化後(52.8)がシード(61.1)を下回ったため、良い方を保存する保険を追加した。

**教訓: 進化探索はシミュレータ忠実度に対する最強のファジングツールである。**
誤読スクリプトが1枚でもあれば、進化は必ずそれを見つけて「一番強い嘘」を
組み上げる(77.0→72.5はどちらも当時の全デッキ中最強級だった)。
高スコアが出たときほど発火源の内訳検証(approx混入チェック)が必須。
指標に使う信号(発火率・chain・ループ署名)は全てexact由来でなければならない。

残課題: ツインパクトの両面プレイ(カーネル機能)、approved approxの
原文照合監査(誤読健診)、コンボ進化がシードを安定して超えるための
多目的バランス調整。


## 第十二弾: トリガー句剥がしの誤読健診——首位が逆転した(2026-06)

三事件の根本原因「トリガー句を含む文全体への素朴なキーワードマッチ」を
構造的に塞いだ。効果抽出の前に文頭のトリガー句(「〜時、」)を取り除く
前処理を生成器に追加し(条件句「〜なら」は意味が変わるため対象外)、
自動承認1,608件を全再生成して差分を健診した。

**結果: 27件のスクリプトが修正された。** 代表例:
- 飛行男/ザビフライ/エミリー: 「破壊された時、相手の手札を捨てさせる」の
  トリガー句「破壊された」が効果側の「相手」と誤結合し、**死ぬたびに相手
  クリーチャー1体を道連れにする捏造除去**が付いていた
- 剛撃妖精ユキハナ: 「捨てられた時」句から捏造ハンデスが生えていた

修正後の統一条件で主要デッキを再測定すると、**順位が逆転した**:

| デッキ | 修正前 | 修正後 | exact発火率 |
|--------|--------|--------|------|
| id=21 黒赤ブリッツ(アグロ+荷物) | 65.1 | **57.9** | 2.5% |
| id=22 邪眼転生ロマノフサイン | 59.1 | **60.1** | 76.4% |
| id=25 黒単戒王リアニメイト | 55.0 | 55.2 | 15.5% |
| id=20 手組みロマノフサイン | 47.5 | 49.6 | 62.7% |

id=21はザビフライ4枚の捏造除去で7.2pt水増しされていた。誠実な物理では
**「勝ちながら回る」id=22が全ロマノフ系の首位**であり、第十弾の
「コンボを回す価格6pt」はほぼ消滅(60.1 vs 57.9で逆にコンボ側が上)。
発火圧付き進化の成果は、シミュレータが正確になるほど価値が上がる。

教訓: 誤読健診は探索の前提インフラである。スクリプトの誤りは特定デッキを
歪めるだけでなく、**デッキ間の比較・進化の選別・研究上の結論(コンボの価格)
まで連鎖的に歪める**。スナップショット→全再生成→差分監査→主要デッキ
再測定、を生成器を触るたびの標準手順とする。

## 第二十五弾: 進化元バグ——アグロ過大評価の真因と「探索のブロッカー盲点」(2026-06)

### 条件付きコスト軽減の無条件適用(進化と同型のバグ)
`summon_cost_reduction`が「自分のビートジョッキーの召喚コストを下げる」等の

唱えるコスト」の型混同まで含む)。マーカー列挙では漏れるため、無条件パターン
`自分のクリーチャー(を|の)召喚コストをN少なくする`を正面から定義し、種族
プレフィックスや条件語を弾く方式に変更。**168種→1種**(真に無条件の念仏
エルフィンのみ)に締まった。

影響は現行デッキにほぼ無し(壁90.4・火単66.3・ペニシリン63.4で安定)。
これは**潜在的搾取経路の予防的封鎖**——探索器は適応度最大化の過程で必ず
こうした過大評価を見つけて搾取するため、ルール側の過大評価も誤読と同様に
先回りで潰す必要がある。誤読類型カタログ(スクリプト)に対応する
「ルール過大評価カタログ」の第2項(第1項=進化元)として記録する。

## 第三十二弾: 頑健性項の実装と「平準化はするが天敵は倒せない」(2026-06)

第三十一弾の知見を探索器に還元し、適応度に最悪マッチアップ勝率項
(`--robustness-weight`)を実装した。`_simulated_metrics`が相手別勝率の最小値を
返し、適応度に`worst_rate × robust_share`を加える(弱者狩りで平均を稼ぐ
デッキを抑制)。

**検証(robustness-weight 0.3の素探索, id=45, 54.9)**: 中位マッチアップは
43〜56%に均された(素プローブid=43の幅広い分布より平坦)が、**壁戦は4%の
まま**。最悪マッチの底は上がらなかった。

知見: **頑健性項は中盤の取りこぼし/blowoutを平準化するが、構造的天敵
(壁=ブロッカーの塊)を倒すには特定技術(ブロッカー除去)が要り、その技術が
シード/プールに無ければ探索は合成できない**。最悪マッチを下げているのが
単一の構造的穴(wall 4%)である限り、項の重みだけでは埋まらない。

結論: 頑健性選別は「必要だが十分でない」。真に頑健なデッキ(id=44赤単メテオ・
覇道=全方位53%以上)は、頑健性項ではなく**反天敵技術(ブロッカー除去)を
持つアーキタイプをシードに**絶対値最適化して得られた。頑健性項の最適な
使い所は、反天敵技術を持つシードとの併用——次はメテオシード+robustness併用で
id=44を超える頑健チャンピオンを狙う。


## 第三十三弾: 頑健性×反天敵シードの実証——真の頑健チャンピオン(2026-06)

**結果: 赤単メテオ・頑健型(id=46, 84.6)**。再較正12デッキ全てに**59〜99%で

バザガジー8000)が火のS・トリガー除去の射程(〜6000)外。

**構造的知見(残存非対称性)**: 壁・進化・ルールの忠実度は固めたが、
**単純な能動戦略(アグロ=攻撃するだけ)はカーネルが完全に忠実にモデル化する
一方、反応的な複雑コントロール(条件付き除去・ライフゲイン・複雑S・トリガー・

被覆バイアス。結果、現プールでは赤単アグロが構造的に最強となる。

含意: この非対称性は「赤単が強い」という本家とも整合する結論を含むが、
コントロール/コンボの真の強さは**控えめに出る**ことを常に念頭に置くべき。
コントロール被覆(防御札のexact化)を進めれば評価はより中立に近づく。
これが次の大きな被覆作業の方向。プールはアグロ偏重を避け12デッキに復帰。

### 第三十七弾・補遺: 被覆ギャップの定量と要塞支配の機構的確証

つまり**要塞の壁は過大評価どころか過小評価**(実カードはほぼ不滅だがモデルでは
通常破壊可能)。それでも要塞は支配的。

**最終結論(支配の忠実性)**: 過大評価3クラス(modal/制限/chooser=69件)を是正し、

ミル11.6%/無制限11.6%/マナ送り3.4%)を退けた。**要塞の支配は評価の歪みの

(特殊勝利10種・静的破壊耐性4種)は小ニッチで、被覆しても均衡を覆す公算は低い。
現エンジンは高インパクト機構について忠実に飽和しており、メタは光闇S・トリガー
要塞で安定均衡に達した、というのが本探求の到達点である。

## 第四十弾: ポリシー感度実験——要塞支配は「無謀な突撃」の産物ではない(2026-06)

第三十九弾までで「忠実評価下で光闇要塞が一強」と結論したが、最後の疑念が残った:
評価方策ComboPolicy(の基底GreedyPolicy)の`choose_attack`は**S・トリガーを
一切警戒せず常にシールドを攻撃する**(`player_attacks[0]`)。実プレイヤーなら
S・トリガー濃厚な相手には突撃を控える。要塞の支配は、相手が無防備にシールドを
割って除去S・トリガーを誘発し続ける「方策の弱さ」の産物ではないか?

**実験**: 挑戦者(アグロ/ミッドレンジ4種)に保守方策(劣勢時はシールド攻撃を
控える=S・トリガー警戒)を与え、要塞id=78への勝率を貪欲方策と比較(各400試合)。

| デッキ | 貪欲(常時攻撃) | 保守(S-trig警戒) | 差 |
|------|------|------|------|
| 赤単メテオ頑健(id=46) | 3.5% | 3.2% | -0.3 |
| 火単紅蓮ビート(id=38) | 0.5% | 0.0% | -0.5 |
| 火の逆襲(id=65) | 16.8% | 14.5% | -2.3 |
| 赤単メテオ覇道(id=44) | 3.5% | 2.0% | -1.5 |

**結果: 突撃を控えると全デッキで勝率が下がった(-0.3〜-2.3pt)**。S・トリガー
警戒は要塞戦で逆効果。理由は明快——要塞は除去+蘇生+シールド増殖(絶十/
DNA・スパーク)で長期戦を制するため、アグロの唯一の活路は**速攻でレースする**
ことであり、突撃を控えれば要塞が盤面とシールドを整えて一層楽に勝つ。

**含意**: 要塞の支配は「相手が無謀に突撃してS・トリガーを誘発するから」では
ない。貪欲な常時攻撃はアグロにとって対要塞でほぼ最適であり、より賢い(慎重な)
プレイを与えてもアグロは勝てない。要塞は受けの誘発ではなく**バリュー(除去+
蘇生+盤面)で上回って勝っている**。方策の質を変えても結論は揺らがない。

総括(均衡の頑健性・最終): 光闇S・トリガー要塞(id=78, 91.3%)の支配は、
(1)忠実評価(過大評価是正76件)、(2)壁の過小評価の確認、(3)7角度の反証
(3.4〜35%)、(4)アーキタイプ天井マップ(単独Tier 0)、(5)色移植不可
(水闇54.4%)、(6)**ポリシー感度(突撃抑制は逆効果)**——あらゆる検証を
くぐり抜けた。要塞は評価アーティファクトではなく、現カードプール×戦闘解決
領域における真の支配戦略である。これが本深層探求の確定的到達点である。


## 第四十一弾: 特殊勝利フロンティアの実証的閉鎖——ミルは要塞の時計に間に合わない

第三十九弾で特殊勝利(シャコガイル等)を「未被覆フロンティア」、補遺で「公算は
低い」とした。これを実測で確定的に検証した。

**実験**: 水のドロー/ミルデッキ(シャコガイル中心)を要塞id=78と200試合対戦させ、
決着理由を計測。シャコガイルの勝利条件「山札を引き切って勝つ」が未実装の現状で、
ゲームがどう終わるかを見る。

**結果(200試合)**:
- direct_attack(要塞がミルを殴り殺す): **196**
- deckout: 4(うち**4件すべてミル側の自滅敗北**)
- ミル側勝利: 1(0.5%)

**含意**: 仮にシャコガイルの勝利条件を実装しても、反転しうるのは自デッキ切れ
敗北の**4試合のみ**(0.5%→約2.5%)。残り196試合は要塞の打点がミルを
コンボ完成前に殺している。**特殊勝利の被覆はメタに実効ゼロ**——ミルは要塞の
時計に間に合わない。第三十九弾で見送ったエンジン改修は、勿体ぶった保留では
なく「やっても無駄」と実証された。

**深層探求の確定的閉鎖**: これで要塞支配への理論的天敵(特殊勝利)も実証的に
否定された。光闇S・トリガー要塞(id=78)の支配は——
忠実評価(是正76件)・7角度反証・天井マップ・色移植不可・ポリシー感度・
特殊勝利の実測無効——**考えうるすべての検証を通過した確定的支配戦略**である。
現カードプール×現エンジン(戦闘解決+デッキ切れ)において、要塞に対する
有効な回答は理論上も実測上も存在しない。本探求はここに完了する。

次に質的変化を起こしうるのは「カードプールの拡張(新カード追加)」または
「特殊勝利+それを操縦できるポリシーの同時実装」(=エンジン+方策の二重改修)
のみ。いずれもユーザーの方針判断を要する大改修であり、現フレームワーク内での
最適化は本弾をもって飽和に達した。


## 第四十二弾: プール拡張①——アンチS・トリガー被覆は反要塞を3倍改善も、なお届かず

ユーザー指示「カードプール拡張」に基づき、要塞への直接的回答となる**アンチ
S・トリガー機構**を被覆した(エンジン+カード property、回帰テスト付き)。

**被覆した新メカニクス**: 「誰も〜のカードのS・トリガーを使えない」(無条件・全体
ロック)。`BattleCard.strigger_lock_civs`でexact-safe検出(per-break型・条件付きは
除外)、`engine._strigger_locked`でシールドブレイク時に文明ロックを判定。
既存185テスト全合格+新規3テスト。これで以下が機能:
- 暴風の求道者フ・レイル(光6): 誰も闇のS・トリガーを使えない
- ギガボルバ(闇4): 誰も光のS・トリガーを使えない

**反要塞デッキの探索結果(対id=78, 各500試合検証)**:

| 構成 | ロック範囲 | vs id=78 |
|------|------|------|
| (参考)火単アグロ ロックなし | — | 6.2% |
| 光闇 両ロッカー | 光闇 全S・T | 15.4% |
| **闇火アグロ + ギガボルバ** | 光S・Tのみ | **19.4%** |
| 光闇火 両ロッカー+火クロック | 光闇 全S・T | 16.0% |

**所見: アンチS・トリガー被覆は反要塞を約3倍改善(6.2%→19.4%)したが、要塞を
倒すには至らなかった**。最良は闇火アグロ+ギガボルバ(速いクロック+光ロックで
DNA・スパークの全タップを封殺)。だが19.4%止まり。

**要塞が耐える機構的理由(深掘り)**:
1. **除去がハードキャスト可能**: 戒王/地獄門/DNA・スパークは on_cast も持ち、
   S・トリガーをロックしても手打ちで除去・全タップできる。ロックは「無償の受け」を
   奪うが「能動的除去」は奪えない。
2. **守備の文明分散**: 闇(戒王/地獄門の除去+蘇生)と光(DNA・スパークの全タップ)に
   守備が分かれており、単一ロッカーでは半分しか止まらない。両方止めるには光闇
   (=速いクロックを欠く色)に縛られる。
3. **ロッカーが遅く除去される**: フ・レイル(6)/ギガボルバ(4)は着地が遅く、
   要塞のハードキャスト除去で処理される。

**結論**: プール拡張の方法論は機能した——新メカニクスを忠実被覆し、反要塞を
3倍改善する新アーキタイプを生んだ。だが要塞の守備は「ハードキャスト可能・
文明分散・除去耐性」の多層構造で、アンチS・トリガー単体では崩れない。これは
要塞の強さがS・トリガー依存ではなく**カード自体のバリュー**にあることの更なる
証left。次の拡張は「ロッカーの保護/高速化」または「要塞のハードキャスト除去を
枯らす手札破壊」との複合が要る。被覆したロック機構は今後の探索資産として残る。


### 第四十二弾・補遺: ロック+ハンデスは行き止まり——プール拡張①の総括

要塞のハードキャスト除去を枯らす狙いで、ロック(ギガボルバ)+ハンデス
(終焉の凶兵ブラック・ガンヴィート=攻撃時に両者手札全捨て、新規被覆)を複合した。
結果は**500試合3.2%**と、純アグロ+ロック(19.4%)より大幅に悪化。理由:
(1)ガンヴィートの手札破壊は対称で自分の手札も消える、(2)7コストで遅い、
(3)要塞はドローで回復し、S・トリガーはシールドから出るため手札破壊が刺さらない。

**プール拡張①(既存カード被覆)の総括**: アンチS・トリガー機構とハンデスを
被覆し、反要塞アーキタイプを複数探索した。最良は闇火アグロ+ギガボルバの
19.4%(火単6.2%の3倍)。だが要塞id=78を倒すには至らなかった。

**根本的な知見**: 要塞の強さは単一の搾取可能なメカニクスではなく、**分散した
カードバリュー(ハードキャスト可能な除去+蘇生+文明分散の守備+ドロー回復)**に
ある。ゆえに既存カードの被覆(アンチS・トリガー/ハンデス)では崩せない。
この要塞を倒すには、現プールに存在しない**質的に新しい強カード/メカニクスの
追加**(=外部の新カードプール導入)が要る。被覆で生まれた均衡は、被覆だけでは
覆せない——S・トリガー被覆が要塞を「作った」が、既存メカニクスの追加被覆では
要塞を「壊せない」という非対称が、本探求の最終的な構造的発見である。

被覆資産(今後も有効): アンチS・トリガーロック機構、終焉の凶兵ガンヴィートの
手札破壊。新カードプール導入時にはこれらが新たな相互作用を生む可能性がある。


### 第四十二弾・補遺2: per-break無効化(ドルザバード)も速度不足——アンチS・トリガー直接路の限界

per-break型S・トリガー無効化(覇竜凰ドルザバード=ブレイクしたシールドのS・トリガーを
不発に)を被覆・テスト(発火2.55→0.95/試合)し、闇火速攻に投入。だが**500試合
6.6%**と、単純なギガボルバ速攻(19.4%)より悪化。理由: ドルザバードは6コストの
進化で攻撃は7ターン目以降、要塞が先に盤面を整える。

**アンチS・トリガー直接路の構造的限界(確定)**: 静的civロック(フ・レイル/
ギガボルバ)・per-break無効化(ドルザバード)・ハンデス複合——あらゆる
アンチS・トリガー手段を被覆・検証したが、**いずれの手段もコスト4〜6と遅く、
速いアグロはそれらを積む余裕がない**。最良は最安(コスト4)のギガボルバを
積んだ闇火速攻の19.4%止まり。要塞の分散バリュー(ハードキャスト除去+蘇生+
ドロー回復)は、遅いアンチS・トリガー技術では崩せない。

**被覆資産(確定)**: 静的civロック・per-break無効化・ガンヴィート手札破壊の
3機構を忠実被覆(全テスト合格)。現プールでは要塞を倒せないが、将来の新カード
プール導入時にこれらが高速・低コストのアンチS・トリガー札と結合すれば、要塞の
受けを崩す現実的な経路となりうる。被覆は「いつか効く下地」として蓄積された。


## 第四十三弾: プール拡張②——「要塞を倒す新カード」の設計仕様を実証的に特定

外部新カードの取り込み(DMPS公式API)はネットワーク許可リスト外で不可、GitHubの
DMカードデータは英語版TCG(和文カーネル非互換)のみ。そこで方針を転換し、
**仮説的な新カードを設計してエンジンに投入し、「どんなカードなら要塞を倒せるか」を
実証的に特定**した(テストカードは検証後に削除、DBは5178枚のまま)。

第四十二弾で「アンチS・トリガー手段は遅く(コスト4-6)、ロック可能な色(光闇)は
速度を欠く」と判明していた。これを変数分解して検証:

| 仮説カード | 対id=78(500試合) |
|------|------|
| 既存ロッカー(フ・レイル6/ギガボルバ4)光闇アグロ | 2.8% |
| 高速ロック c3(光闇) | 9.8% |
| 最速ロック c2(光闇) | 13.2% |
| **火 速攻ロッカー c3**(SA+光闇S・T両ロック) | **28.0%** |
| **火 速攻ロッカー c2**(SA+光闇S・T両ロック) | **53.8% ← 勝ち越し** |

**決定的発見: 要塞は原理的に倒せる**。鍵は「**ロック+クロックの一体化**」——
速い攻撃的ボディ(火・スピードアタッカー)と要塞のS・トリガー(光闇両方)を
封じる能力を**1枚に統合**したカード。これがあれば、要塞のシールド由来の受けを
封じながら速攻で殴り切れる。

**現プールに存在しない理由**: 実在のロッカーはロックが単一文明・コスト4-6・
守備的な光闇に分散している。「火の速いボディ+多文明S・トリガーロック」を兼ねる
カードが現5178枚に無いことが、要塞支配の根本原因。

**現実性の考察**: コスト3版は28%(改善も勝てず)、コスト2版で初めて勝ち越し
(53.8%)。コスト2で全相手S・トリガーを封じるSAは実カード基準ではやや過剰。
ゆえに「要塞は現実的な新カードにも頑健だが、やや尖った1枚(安価・攻撃的・
多文明S・トリガーロック)が来れば崩れる」。

**要塞を倒す新カードの設計仕様(ユーザー向け・取り込み時の探索条件)**:
- 文明: 火(または他の攻撃的色)
- コスト: 2〜3、スピードアタッカー等の速いボディ
- 能力: 「誰も光のS・トリガーを使えない」かつ「誰も闇のS・トリガーを使えない」
  (=要塞コアの光闇S・トリガーを両封じ)、または「誰もS・トリガーを使えない」
この条件に合う実カードが新カードプール(DMPS全集・OCG)に在れば、取り込みで
メタは動く。**プール拡張の方法論はここに完結**——「何を入れれば変わるか」が
具体的に判明した。被覆資産(ロック機構)はその受け皿として既に整備済み。

(検証用の仮説カードTEST-*はDBから削除済み。cards総数5178枚不変。)


## 第四十四弾: db内アンチ要塞機構の総被覆——呪文ロックも含め、ceiling は約20%

「dbの中でやり切る」前提のもと、要塞の急所(除去の5/8が呪文)を突く**呪文ロック**を
db内被覆し、アンチ要塞機構を出揃わせた上で上限を確定した。

**被覆した全アンチ要塞機構(db内・テスト付き)**:
1. 静的civ S・トリガーロック(フ・レイル=闇/ギガボルバ=光) — 第四十二弾
2. per-break S・トリガー無効化(ドルザバード) — 第四十二弾
3. **呪文ロック(チューザ=タップ時全呪文/アルカディアス=光以外)** — 本弾
   - engine._spell_cast_blocked: 場の呪文ロックで両者の呪文詠唱・呪文S・トリガーを封殺
   - 検証: チューザ投入で呪文S・トリガー発火 2.52→0.03/試合(ほぼ完全抑制)

**対要塞id=78の結果(各500試合)**:

| デッキ | 封じる範囲 | vs id=78 |
|------|------|------|
| 火アグロ+チューザ | 全呪文S・T | 11.4% |
| 光闇+アルカディアス | 闇呪文S・T | 0.8% |
| 火闇 ギガボルバ+チューザ | 光S・T+全呪文S・T | 10.2% |
| (第四十二弾)闇火+ギガボルバ | 光S・T | 19.4%(最良)|

**所見: ロック機構は完璧に動作するが、要塞は倒れない**。呪文S・トリガーを
0.03/試合まで潰しても要塞は約90%勝つ。理由が機構的に確定した:

**db内ロッカーは「遅い・クロックにならない」**。ギガボルバ(4)・チューザ(4)・
フ・レイル(6)はいずれもS・トリガーを封じる「ユーティリティ・ボディ」であり、
打点を進めない。デッキは攻撃の代わりにロッカー設置にターンを費やし、その間に
要塞は素のボディ(キラーアイ/天鎖/デス・サークル/イーター/シャイニー)と
creature S・トリガー(生け贄除去)で盤面を固め、長期戦を制す。

第四十三弾で勝てた仮説カード(コスト2・スピードアタッカー・多文明S・トリガー
ロック=53.8%)は「**ロック能力と速いボディを1枚に統合**」していた。db内には
この統合カードが存在せず、ロックとクロックが別カードに分離している。これが
要塞のdb内ceiling=約20%の正体。

**結論(db内で確定)**: 要塞id=78は現dbの真のチャンピオン。アンチS・トリガー機構を
全て被覆して機能させても、db内の反要塞デッキは約20%が上限。要塞を倒すには
「安価・攻撃的ボディ+多文明S・トリガーロックを兼ねる1枚」が要るが、それは
現dbに存在しない。被覆した3機構(civロック/per-break/呪文ロック)は、もし
将来そうした統合カードがdbに加われば即座に協働する受け皿として整備済み。


## 第四十五弾: 「ロックとクロックの分離」は解消できるか——トレードオフ曲線で確定

ユーザー問い「ロックとクロックが別カードという構造限界の解消は db 内で可能か」を
実証実験で検証した(各400試合, scripts/exp_double_lock.py / exp_clock_max.py)。

**db内のS・トリガーcivロッカーは厳密に2枚のみ**:
- ギガボルバ(闇c4 → 光ロック)
- 暴風の求道者フ・レイル(光c6 → 闇ロック)
要塞は光闇なので、S・トリガーを完全封殺するには両方=火闇に光スプラッシュの3色。

**ロック方向(深める)**:

| 構成 | 封じる範囲 | vs id=78 |
|------|------|------|
| id=82 baseline (ギガボルバのみ) | 光S・T | 19.5% |
| dual lock (+フ・レイル×4) | 光S・T+闇S・T | 17.2% ↓ |
| only-dark (フ・レイルのみ) | 闇S・T | 15.2% ↓ |

**反直感的結果**: 闇ロックを足すと**悪化**。要塞の防御の柱は光S・トリガー
(壁/ブロッカー)で、ギガボルバが既に止めている。闇ロックに枠を割く=クロックを
削る純損。「ロックが半分しか効いていないから弱い」という仮説は否定された。

**クロック方向(速める)**:

| 構成 | vs id=78 |
|------|------|
| pure-aggro (ロック無し・全速攻ボディ) | 7.0% |
| clock-max + ギガボルバ | 10.2% |
| id=82 (地獄門・革命入りミッドレンジ) | 19.5% |

純速攻に振ると要塞の壁ブロッカーに止められ7%まで崩落。ギガボルバは確かに
+3pt効く(7.0→10.2)が、速攻ボディ偏重では耐久・除去(地獄門)を失い逆に弱い。

**結論(トレードオフ曲線)**: 分離の解消は db 内で**不可能**。
- ロックを深める → クロックが痩せる(17.2%)
- クロックに振る → ロック+耐久が痩せる(7〜10%)
- 両者のスイートスポットが id=82 = 19.5%

id=82(19.5%)は反要塞探索の**局所最適**であり、これ自体が天井の所在を示す。
「安価・攻撃的ボディ+多文明S・トリガーロックを1枚に統合」したカードが無い限り、
このトレードオフ前線は動かない。第四十四弾のceiling≈20%を、今度は両軸の
微分(深める/速める双方が悪化)で挟み込んで確定した。

新規性=デッキ採用カードのうち現メタ199語彙に無い種類の割合(高いほど未開拓)。

**所見: メタは二層構造**。9方向すべてが同じ天井(35〜49点)に収束した。
- **要塞層**(光闇S・トリガー要塞6系統): 互いの鏡で約50%、フィールドを蹂躙し
  フルメタ84〜91%。トップ帯を構造的に独占。
- **フィールド層**: 要塞6枚に**ほぼ自動0%負け**(6/21=29%が0%付近)するため、
  残り15戦を全勝しても平均は約64%が上限。実際は非要塞戦も取りこぼし35〜49点。

新規性は軒並み80〜100%——**未開拓カードは大量にあるが、どれも要塞を崩せない**。
「未開拓デッキの不在」ではなく「未開拓カードで要塞層に到達する経路の不在」が
正体。最良の未開拓型は闇単(ドルバロム+ハンデス制御, 49.4点)だが要塞には3〜17%。

**残る未踏フロンティア**: 本探索はすべてgreedy操作。コンボデッキ(墓地詠唱・
mill・マナロック等、シールドを介さず勝つ経路)はgreedyが過小評価するため未探索。
S・トリガー防御を迂回し得る唯一の方向として、次にComboPolicyで掘る。


## 第四十七弾: フィールド層の真の天井を確定——闇単精錬で約67%(対非要塞)

第四十六弾の最有力「闇単ハンデス制御」を起点に深掘り精錬(22世代×18個体、
robustness_weight=0.3)し、非要塞15デッキに対する真の到達点を測った
(scripts/deep_field_refine.py)。

**結果**:
- 闇単シード: 非要塞フィールド平均 65.6% / フルメタ49.4
- 精錬後: 非要塞フィールド平均 **67.0%** / フルメタ51.6 (+1.4pt、収束)

**フィールド層内の最弱マッチ=S・トリガー火コントロール(12〜17%)**。
赤単メテオ(35%)も渋い。逆に火水レイド/光単裁き等の純ビートには9割超。

**所見: フィールド層の天井は約67%(対非要塞)で、壁は「S・トリガー制御サブ層」**。
火コントロール(84.8/85.7)も要塞と同じくS・トリガー防御を持つ"小要塞"であり、
これを崩すには反S・トリガー機構が要る=要塞本体と同じ20%の壁に行き着く。
つまりメタは入れ子: 要塞 ⊃ S・トリガー制御 ⊃ ビート、とS・トリガー防御の
厚みで階層化している。非要塞デッキはこのサブ層に阻まれ67%で頭打ち。

**精錬後の闇単(db最強の非要塞デッキ)**:
ジュランデス4/ステニャンコ4/特攻人形ジェニー4/無防備のザビ キナコ4/
ジンロウ・ドレイク4/変身人形イルルカ3/ギガクローズ3/フェリックス・ミザリィ3/
邪魂創世2/共倒れの刃2/死神ハンド2/他1枚刻み6種。
速い闇ボディ+ハンデス+軽量除去でビート系を制圧する純闇単アグロ制御。


## 第四十八弾: 無制限(全5178枚)探索でも要塞層に届かず——apex不在を確定

civ制約なし(全色)で深掘り探索した結果、フルメタ強さ36.7点・対要塞1.7〜8%。
**全カードプール・無制約でも要塞層に到達しない**。むしろ焦点を絞った闇単(49.4)
より低い——5色の烏合はマナ不整合で焦点デッキに劣る(coherent focused > unconstrained)。

これで「db内に未発見のapexは存在しない」が最強の形で確定:
- 9 civ-combo探索: 全て35〜49点
- 闇単深掘り精錬: フルメタ51.6 / 非要塞67%
- 無制限深掘り探索: 36.7点

メタの3 apex(光闇S・トリガー要塞 / 火S・トリガーコントロール / 青黒白ブロッカー
ウォール)は全て「厚いS・トリガー/壁防御」を共有。第4のapexは現dbのgreedy探索
空間に存在しない。未開拓カードは豊富だが、それらで要塞層に至る経路が無いことが
4方向(lock軸/speed軸/control軸/無制約)から確定した。


## 第四十九弾: 定義版要塞は唯一無二の絶対apex——全21メタデッキが敗北

「他の高評価デッキ(火コントロール85.7/青黒白ブロッカー89.8)は要塞に勝てるのか?
=要塞は三すくみの一角か絶対王者か」を直接検証。全21メタデッキ vs 光闇要塞・定義版
(各160試合)の結果:

| 挑戦者 | vs 定義版 |
|---|---|
| 光闇要塞・修正後王者(兄弟) | 33.8% |
| 光闇要塞v2(兄弟) | 31.9% |
| 光闇要塞v3(兄弟) | 30.6% |
| S-trigger火コントロールv2 | 18.1% |
| 火の逆襲(反要塞特化) | 13.8% |
| 青黒白ブロッカー(89.8) | 1.2% |
| 赤単メテオ(84.6) | 1.2% |
| 火単紅蓮(86.5) | 0.6% |
| 残り全て | 0〜4% |

**結論: 定義版は co-apex の一角でなく、兄弟要塞すら30%台に抑える唯一無二の
絶対王者**。火コントロール/青黒白ブロッカーが高フルメタ(85〜90%)なのは、
弱い要塞変種とフィールドを叩くためで、定義版本体には1〜18%で完敗する。
非要塞最善はS-trigger火コントロール18.1%(反要塞ceiling≈20%と整合)。

これで「未開拓デッキの不在」が最終確定: 発見済み21デッキも、夜間に探索した
17 civ-combo+無制限の未開拓型も、誰一人 定義版 に勝てない(全て<34%、非要塞<19%)。
**「要塞を倒す未開拓デッキ」は存在しない。db内で 定義版要塞 は真の終着点。**
残る唯一の理論的余地は engine 未模擬の「マナロック/mill によるS・トリガー
迂回勝利」のみ(destroy_man op 不在のため検証不能)。


## 第五十弾: 最後の軸「マナロック(ドルバロム)」をengine実装の上で封鎖

第四十九弾で残した唯一の理論的余地=「マナロック/millによるS・トリガー迂回勝利」を
検証可能にするため、既存カード ドルバロムの効果をexact実装した(忠実被覆)。

**実装(純加算的・既存op不変、tests/test_destroy_mana.py)**:
- `destroy_mana` op: keep_civ指定で非該当文明のマナを墓地へ、scope=bothで両者に適用
- `destroy_creatures_nonciv` op: 指定文明を持たないクリーチャーを全破壊、scope=both
- 悪魔神ドルバロム(83400/83420)を exact 承認: 出た時、各プレイヤー闇以外マナ全破壊
  →闇以外クリーチャー全破壊(対称・keep_civ闇)。承認exact数 39→40。
- 全194テスト緑、メタ21デッキはドルバロム不使用=既存評価に影響なし。

**対要塞テスト(各300試合)**:

| デッキ | vs 定義版 | 効果無効版 | mana破壊発火 |
|---|---|---|---|
| ドルバロム闇単 | 1.7% | 1.7% | 0回/40 |
| 闇自然ramp-ドルバロム | 2.3% | 2.3% | 0回/40 |

**所見: マナロック軸も封鎖**。ドルバロムは効果あり/なしで勝率が完全に同値、
発火0回——cost10進化が要塞のクロック(平均12.6ターンで決着)前にほぼ解決しない。
遅い相手でも40試合に1回しか組めず、assembly自体が壁。仮に解決しても闇以外しか
ロックせず光闇要塞の闇半分は生存=非対称ロックにならない。

**最終確定(全6軸)**: 定義版要塞は、(1)S・トリガーロック≈20% (2)速攻7-10%
(3)制御17%(フィールド最善) (4)無制限36.7 (5)mill(enabler 0枚) (6)マナロック2.3%
——engineが模擬する全ての戦略軸で無敗。db内に要塞を倒すデッキは、発見済みも
未開拓も存在しない。コントロール被覆プロジェクトの探索空間はここに飽和した。


## 第五十一弾: 最多用メタカードの過大評価を是正——天井は約20%でなく約25%

夜間探索の信頼性を高めるため、最多用メタカード(要塞・上位が多用)の効果忠実性を
監査したところ、複数のapprox効果が**自己利益を相手除去として二重計上=過大評価**
していた。exact-safe原則(過小評価側に倒す)で3枚を是正:

| カード | 採用 | 旧approx(過大) | 是正後 |
|---|---|---|---|
| 魂穿ツ煌世ノ正裁Z | 6デッキ | 無制限destroy×2 | コスト8以下1体除去(自己シールド化は未模擬) |
| 地獄門デス・ゲート | 5デッキ | destroy×2 | アンタップ1体破壊+墓地蘇生 |
| 改造治療院 | 5デッキ | discard×2 | 手札1捨て+墓地回収 |

**是正の影響(各200試合, vs 定義版要塞)**:

| 挑戦者 | 補正前 | 補正後 |
|---|---|---|
| S-trigger火コントロールv2 | 16-18% | 25.5% |
| 火の逆襲(反要塞) | 13.8% | 26.0% |
| 赤単メテオ | 3.0% | 9.5% |
| 非要塞最善 | 18.1% | **25.5%** |

**所見: 要塞の支配は過大評価された除去スイートに底上げされていた**。要塞自身も
これらを多用するため、是正で要塞の防御が相対的に弱まり、挑戦者が25%台まで届く。

**結論の更新**: 質的結論(定義版要塞は無敗、誰も36%超えず非要塞は26%未満)は不変。
ただし**反要塞ceilingは約20%でなく約25%**が正確。第四十五〜五十弾の絶対数値は
すべて過大評価層での測定であり、是正後は各軸+5〜7pt上振れする(が要塞超えには
至らない)。「ロックとクロックの分離」「6軸で無敗」の構造的結論は是正後も成立。

(注: 監査は最多用5枚中3枚を是正。紅の猛り天鎖/戒王の封も要レビューだが、
天鎖はT・ブレイカー本体・戒王はSST条件付きで影響は相対的に小さい。残approx
3416枚の全面監査は別途。本是正は要塞結論に直結する高採用3枚に限定した。)
