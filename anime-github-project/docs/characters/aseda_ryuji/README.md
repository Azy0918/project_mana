# 汗田 竜司 Character Notes

## 基本情報

- 名前: 汗田 竜司
- 読み: あせだ りゅうじ
- 年齢: 54歳
- 職業: 自動車開発者、研究職
- 所属: 大手自動車メーカー 研究本部 / 先進技術開発部門
- 経験: 30年以上

## 見た目

- 黒髪の長めの髪、無精髭
- 紫系のサングラス
- 落ち着いたジャケット、ライディングウェア、ブーツ
- 紫のヘルメットと大型アドベンチャーバイク
- 表情は通常、困惑、驚き、真剣、ツッコミ顔の差分あり

## 性格

- 真面目なインテリ
- 論理的で慎重
- 責任感が強く、妥協を許さない
- 会社や組織の都合に疲れを感じている
- 趣味に触れると少し柔らかくなる

## 背景

大学院修了後、大手自動車メーカーの研究所に入り、30年以上にわたりパワートレイン、制御技術、電動化、次世代モビリティなどの先進技術に関わってきた。

かつては研究にすべてを捧げていたが、短期利益や組織都合が優先される現実に虚しさを感じている。50歳を過ぎてバイクの免許を取り、ツーリングやキャンプ、ウクレレを通じて「自分の時間」を取り戻しつつある。

## 趣味

- バイクツーリング
- キャンプ
- メカいじり、カスタム
- 写真撮影
- 読書、技術書
- 日記、メモ
- ウクレレ演奏
- コーヒーを淹れる時間

## 第十三レジでの使い方

汗田は、未来側の技術や移動手段と相性がよいキャラクター。未来の会社員よりも年上で、技術の背景を理解できる「現実側の専門家」として使える。

### 役割案

- 未来の商品や時空配送技術に、技術者目線で疑問を投げる
- タクミの勢いに対して、冷静にツッコミを入れる
- エリの無表情な判断に、研究者としての倫理観で対抗する
- 第十三レジの挙動を「機械としておかしい」と見抜く
- バイクのナビが未来からのSOSを受信し、第十三レジへ誘導される

### 第2話案

「ナビが未来を案内しました」

会社帰りの汗田は、愛車のナビに突然表示された「第十三レジを探してほしい」というSOSを追って、深夜のコンビニへ辿り着く。そこにはタクミ、エリ、そして未来とつながる不思議なレジがあった。

研究にすべてを捧げた男が、趣味を通じてもう一度未来とつながる話。
