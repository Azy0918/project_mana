# 研究知見: ヒューリスティック評価と厳密シミュレーションの乖離 (2026-06)

進化探索→厳密レーティングのループ(`evolve-rate`)を3つの重みプリセットで実行した結果。
games=100/seed=11/combo方策。

## 主要な発見

**ヒューリスティック適応度が最高のデッキが、厳密シミュレーションでは最弱クラスだった。**

| 候補 | ヒューリスティック適応度 | 厳密強さスコア(対メタ平均勝率×100) |
|---|---|---|
| 強さ重視 best_overall | 41.15 | **17.8** |
| 強さ重視 best_novelty | 40.45 | **45.8** |
| メタ適性重視 best_overall | 36.05 | 20.8 |
| メタ適性重視 best_novelty | 34.85 | 45.8 |
| バランス best_overall | 40.2 | 34.8 |

ヒューリスティック(タグ・カーブ・文明バランス)は「形の整ったデッキ」を最高評価するが、
実対戦では効果の質と速度が支配的で、評価が逆転する。**候補選別をヒューリスティック
のみで行うと、本当に強い候補を捨てている可能性が高い。**

### 示唆

1. 進化探索の選別関数に厳密レーティングを組み込む価値が大きい
   (`apply_sim_strength` の比重0.3は控えめすぎる可能性。実戦データでの回帰が待たれる)。
2. `evolve-rate` を探索の最終段だけでなく世代内選別に使う「ハイブリッド探索」が次の一手
   (計算コスト: 1候補100試合 ≈ 0.1秒なので世代14体×10世代でも約2分)。

## ハイブリッド探索の結果(実装済み: `hybrid-search`)

上記の示唆2を実装した。世代内選別を「対メタ勝率×100×0.7 + ヒューリスティック×0.3」で行う。

```bash
python -m src.battle.research --games 100 --seed 11 hybrid-search --generations 10 --population 14
```

- 世代内の最良勝率が 57.8% → 72.2% へ単調に近い改善(10世代、約11秒)
- 最終候補の全メタ総当たり: **絶対強さスコア 52.4**
  (従来のevolve-rate最高 45.8、ヒューリスティック最高デッキ 17.8 を上回る)
- 相性: 対 自然単 70% / 対 スコーラー 67% / 対 光単 53% / 対 レイド系 36%

ヒューリスティック単独探索より明確に強い候補へ到達することを確認。

### 選別相手のローテーション(過適合対策のアブレーション)

選別相手3デッキへの過適合を抑えるため、相手のローテーションを実装して
4シード(3/7/11/23)で最終候補の全メタ判定スコアを比較した。

| 方式 | 平均 | 範囲 |
|---|---|---|
| 毎世代ローテーション | 61.1 | 52.0〜70.4 |
| 固定相手(従来) | 64.9 | 60.2〜70.8 |
| **周期3ローテーション(既定)** | **65.4** | 60.6〜76.2 |

毎世代の全交代は選別シグナルを揺らして収束を阻害し、かえって悪化した。
3世代ごとに窓をずらす緩やかな交代が、固定相手と同等以上の平均を保ちつつ
全メタデッキを選別に登場させる。既定は `rotation_period=3`
(`--rotation-period` / `--no-rotate` で変更可)。
ただし現状メタは5デッキと小さく、差はノイズ範囲(n=4)。メタプールが
増えるほどローテーションの効果は大きくなる見込み。

### アプリ接続(成果デッキの保存)

`hybrid-search` は既定で最良候補を `generated_decks` に保存する(`--no-save` で無効化)。
candidate_origin='hybrid_search'、戦略メモに強さスコアと相性を記録。
アプリの生成デッキ一覧から閲覧でき、`rate-generated --id N` で再判定できる。

seed=23 の探索成果(id=2, 強さ76.2)は再判定でも73.7となり、
**全メタデッキに勝ち越す初の候補**(対火水57%〜対スコーラー90%)。

## 自己対戦型メタ拡充(PSRO方式、実装済み: `meta-expand`)

外部の収集サイトはこの実行環境から403で到達できないため、メタ拡充は
「ハイブリッド探索の勝者を相手プールへ昇格させ、次ラウンドは拡張メタに挑む」
自己対戦ループ(PSRO的反復)で行う。

```bash
python -m src.battle.research --games 100 --seed 41 meta-expand --rounds 3 --threshold 55
```

実行結果(3ラウンド): プール5→8デッキ。各勝者は拡張後メタへの判定で
74.2 → 61.3 → 69.3 と閾値55を超え続けて昇格(スコアは対象メタが強くなるぶん変動)。

拡張メタ(8デッキ)での総当たり:
自己対戦R1 67.9% > 自己対戦R3 67.1% > 火水レイド 62.6% > 自己対戦R2 59.0% >
火光レイド 46.9% > 光単 39.4% > スコーラー 27.6% > 自然単 27.0%

**探索が発見したデッキが収集メタの最強(火水レイド)を上回った。**
プールが8デッキになったことで選別相手ローテーション(窓3)の巡回パターンも増え、
過適合対策が実質的に機能する規模になった。閾値未満になるまで回せばメタの
飽和点(近似ナッシュ均衡の代理)が観測できる。

## カバレッジ進捗

- 承認済みEffectScript: 21.4% → **32.3%**(1,670/5,178枚)
- 進化探索の上位デッキで使われていた未承認カードの分析から、進化ハイフン表記・侵略行・
  墓地条件G・ゼロ・「見て墓地に置く」・マナ回収(`mana_to_hand` op)等を追加対応。
- 残る未承認はゴッド・超次元・ガチンコ・ジャッジ等の大型メカニズムが中心。
