# 第十三レジ 出現位置 固定設定

> **【固定】** 第十三レジは作品**全話を通して必ず同じ場所に出現**する。出現位置は変更しない。
> 本体デザインは [`../../characters/register13/MASTER_PROMPT.md`](../../characters/register13/MASTER_PROMPT.md)、店内全体は [`FLOOR_PLAN.md`](FLOOR_PLAN.md) を参照。

## 出現場所

- **レジカウンター右端（カウンター上のグレータイルの位置）。**
- 通常時はその位置に、**薄いグレーの四角いタイル（マーカー）だけ**がある（→「位置の目印」節・固定）。
- 午前2時17分になると、音もなくその薄いグレーの四角の真上に第13レジが出現する。

## 出現演出（毎回同じ）

- 蛍光灯が一瞬だけ瞬く
- 店内の電子音が止まる
- 第13レジだけが現れる
- 壁・床・カウンターは変化しない

**巨大なエフェクトは禁止。**

## 消滅

- 午前2時20分。レジだけ消える。跡は残らない。

## 周囲の設備（毎回固定）

- 左：通常レジ
- 右：カウンター端
- 後方：バックヤード入口
- 斜め左奥：コーヒーマシン
- 遠景：コピー機

## キャラクター位置

- **タクミ**：通常レジ担当。異常が起きると右を向く。
- **エリ**：第13レジも普通に操作する。立ち位置は毎回ほぼ同じ。
- **汗田**：客側から第13レジを見る。必要に応じて店員側へ回る。
- **未来会社員**：第13レジの正面。普通の客と同じ位置。

## 出現条件

- 午前2時17分。毎回同じ。タイミングは変更しない。

## 禁止事項（絶対に変更しない）

床から生える／コピー機横に出現／雑誌棚前に出現／客席に出現／バックヤードに出現／店外に出現／浮遊する／巨大化する／毎回違う場所に出現する

## 【最重要】

第十三レジは「**カウンター右端（グレータイル）**」にしか現れない。
視聴者が「あ、2時17分だからあそこに出る」と自然に分かることを目標とする。

---

## 位置の目印 ＝ グレータイル（固定・正式採用）

位置を安定させるため、**視覚的な目印を固定要素として正式採用**する。

- **カウンター天板上のその位置（カウンター右端）だけ、薄いグレーの四角いタイル（マーカー）が常にある。**
  ※第十三レジは卓上サイズなので、マーカーは床ではなく**カウンター天板上**に置く。
- 普段は誰も気にしない、ただの薄いグレーの四角。
- 2時17分になると、その薄いグレーの四角の**真上にぴったり**第13レジが現れる。
- 2時20分に消えると、再び**ただの薄いグレーの四角**（カウンターの空きスペース）に戻る。
- このタイルは**全話で同じ位置・同じ大きさ・同じ色**に固定する。第13レジ本体とサイズが一致する（卓上POSの設置面ぴったり）。
