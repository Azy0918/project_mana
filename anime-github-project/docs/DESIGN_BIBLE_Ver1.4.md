## 深夜二時の第十三レジ ｜ 共通固定設定（デザインバイブル）

> **【固定】** 作品全12話を通して、世界観・店舗・レイアウト・小物・演出・画風・色彩・時間ルールを統一し、シリーズとして一貫性を維持する。
> 個別の詳細は各設定docを参照：キャラ → `characters/README.md`・共通ルール `characters/COMMON_RULES.md`、店舗 → `settings/store_interior/MASTER_PROMPT.md`・見取り図 `settings/store_interior/FLOOR_PLAN.md`、第十三レジ出現 → `settings/store_interior/REGISTER13_APPEARANCE.md`、設備・未来商品 → `settings/props/MASTER_PROMPT.md`。

---

### 世界観（固定）

- 作品世界は**現代日本・地方都市・24時間営業のコンビニ**。近未来都市ではない。サイバーパンクではない。世界は普通。
- 異常なのは **第十三レジ／未来商品／未来物流／未来配送** だけ。
- 空気感は **日常9：SF1**。笑いは **ギャグ7：SF3**。
- 事件が起きても営業は続く。**必ず最後はコンビニ業務へ戻る。**

### 店舗（固定）

店舗レイアウトはシリーズ全話で固定（変更禁止）：入口／駐車場／自動ドア／おにぎり棚／飲料棚／雑誌棚／コピー機／カウンター／13番レジ／ホットスナック／コーヒーマシン／バックヤード／冷凍庫／廃棄ボックス／白板。**位置変更禁止。**（詳細＝見取り図）

### コンビニ外観（固定）

- 地方都市・国道沿い・駐車場あり・街灯・青白い照明。
- 店は古すぎず新しすぎない。
- **チェーン名は表示しない。実在チェーンを描かない。**

### ライティング（固定）

- 深夜。LED照明。青白い色温度、少し紫を含む。コントラストは弱め。暖色は少ない。
- **SF演出時のみ**、青白い光が少し強くなる。

### カメラルール（固定）

- 人物は中央付近。9:16縦画面。頭上・左右に余白。
- **下30〜40％は字幕スペース。**
- 極端な俯瞰禁止／極端な煽り禁止。人物の顔を優先。背景は世界観維持。

### 画風（固定）

- 2Dアニメ／セルルック／ビジュアルノベル／ゲーム立ち絵／アニメ背景美術。
- **禁止**：フォトリアル／厚塗り／3DCG風／ディズニー風／ジブリ風／アメコミ風。

### レシート（固定）

- 第十三レジのレシートデザインは毎回同じ。感熱紙・モノクロ印字。
- 最後に一言だけ異常な内容が追加される。例：店長確認　未了／人類生存率　微増／本日の営業　継続中。

### コピー機（固定）

- 大型白色複合機。雑誌棚横。位置変更禁止。
- **未来の紙だけ印刷される**（本体は普通）。

### 未来商品（固定）

- 普通のコンビニ商品に見える。**未来感はパッケージ名だけ**。派手なSFデザイン禁止。
- 例：昨日バニラ／明日ミルク／反省コーヒー／完全栄養おにぎり・思い出の鮭／店長確認待ちゼリー。

### 第十三レジ 演出（固定）

毎回同じ：蛍光灯が一瞬点滅 → 店内が静かになる → 電子音 → 第十三レジ出現 → 営業開始表示 → **2:20**になると消える。
**巨大エフェクト禁止／爆発禁止。**（→ `settings/store_interior/REGISTER13_APPEARANCE.md`）

### 音演出（固定）

- **店内BGMなし。**
- 聞こえる音：冷蔵ケース／蛍光灯／電子レンジ／コピー機／POSレジ／自動ドア。
- **SF時のみ**：第十三レジ起動音（`assets/sfx/register13_start.wav`）。

### 時間ルール（固定）

- 第十三レジは毎回 **2:17起動 / 2:20終了**。変更禁止。

### 演技（固定）

| キャラ | 演技の軸 |
|---|---|
| タクミ | リアクション最大 |
| ミナ | リアクション最小 |
| 汗田 | 理屈担当 |
| 未来会社員 | 普通の会社員 |
| 座木山 | 日常側の狂気 |
| 唐沢 | 現実側の圧力 |
| 第十三レジ | 無機質 |
| ナビ | 事務的 |

### 作品ルール（固定）

- 未来技術は**生活用品の延長**として描く。未来人も普通の会社員。宇宙人も基本は伝票や通知だけ。
- 事件の解決は**必ずコンビニ業務で行う**：レジ／返品／袋分け／棚卸し／発注／廃棄／コピー機／レシート。**これら以外で解決しない。**

### 店長ルール（固定）

- **店長は画面に出さない**（深夜2時以降は出ない）。
- 「店長確認　未了」「店長呼出」などは使うが、**本人は登場しない**。不在のまま業務が回るのが深夜コンビニ。

### 宇宙・未来物流の描写ルール（固定）

- 宇宙人・未来側は、基本**伝票・通知・レシート・配送コンテナ・画面表示だけ**で表現する。
- 宇宙船・宇宙人・月面基地などを直接派手に描かない。
  - 例：**宇宙宅配便（EP07）＝普通の配送伝票/コンテナ**、**月面店（EP08）＝通知画面**、**銀河ポイントカード（EP09）＝普通のポイントカード風**。
- 「異常なのは中身・名前・通知だけ、見た目はコンビニの日常」を貫く。

### ナレーション 語り口（固定）

- **三人称・淡々・深夜の落ち着いたトーン**。情景と状況を簡潔に語る。
- 声＝澤原玄二郎（→ `characters/VOICE_CAST.md`）。煽らない、説明しすぎない。

### 禁止事項（絶対禁止）

巨大SF装置／未来都市化／空飛ぶ車／ホログラム広告だらけ／ロボット店員／ネオン街／研究所化／軍隊／戦闘／魔法／ファンタジー／異世界転生／サイバーパンク／ホラー演出／グロテスク表現／過剰な未来デザイン。

---

### 【最重要】

本作品は「**普通の深夜コンビニ**」が舞台である。
視聴者が「**本当にありそう**」と思える世界観を維持する。異常なのは第十三レジと未来物流だけで、それ以外は現実そのまま。
作品全12話を通して、キャラクター・店舗・レイアウト・小物・演出・画風・色彩・世界観・時間ルールをすべて統一し、シリーズとして一貫性を維持すること。

## 映像・字幕仕様 固定設定

> **【固定】** YouTube用本編動画の出力仕様と字幕・タイポグラフィを全話で統一する。レンダラ：`anime-github-project/tools/build_episode_video.py`。

### 映像仕様

- アスペクト：**縦9:16**／解像度 **1080×1920**／**30fps**／H.264＋AAC、mp4。
- 構成：**タイトルカード3秒** → 本編 → **エンドカード4秒**。
- 上部に「**第N話　タイトル**」バッジを常時表示。下端に**進行プログレスバー**（緑）。
- BGMなし（環境音中心、SF時のみ第十三レジ起動音）。

### 字幕・タイポグラフィ（全カット固定）

- フォント：**Yu Gothic**。
- **本文（セリフ）**：56px、色＝アイボリー **#F1E8D2**、黒縁取り3px。**下三分の一の対話ボックス内**（枠：x40 / y1440 / 幅1000 / 高さ330）。
- **話者ラベル**：本文の上に小さく、40px、**緑 #A6C178・太字**。書式は「話者名＋改行＋本文」。
- **タイトルカード**：64px。シリーズ名「深夜二時の第十三レジ」（緑）＋「第N話」（大）＋話タイトル。
- 色設計：**アイボリー本文＋緑アクセント＋黒縁**。**下30〜40％は字幕セーフエリア**として人物・重要情報を置かない。
- 長いセリフは**自動でフォント縮小**してボックス内に収める（はみ出し禁止）。
- 字幕中間ファイル（`*_subs.ass`）はレンダー時の生成物（gitignore）。

### カラー定数

| 用途 | 色 | コード(ASS) |
|---|---|---|
| 本文・タイトル | アイボリー #F1E8D2 | `&H00D2E8F1&` |
| アクセント（話者名・枠・バー） | セージグリーン #A6C178 | `&H0078C1A6&` |

必ず毎回同じ顔にする。

- 常識人。読者と同じ目線。

### 【基本表情固定】

デフォルト表情は——

- 少し困っている
- 少し戸惑っている
- 少し眉が下がる
- 少し口が開く

- **驚く時**：目が丸くなる／眉が上がる／口が少し開く
- **焦る時**：眉を八の字／少し前のめり
- **ツッコミ時**：少し身を乗り出す／手を軽く上げる／困った顔

怒鳴るキャラではない。

### 【感情表現】

感情は豊か。表情が毎回変わる。ただし、顔そのものは絶対に変えない。

### 【変更禁止】

イケメン化／主人公補正の強い顔／クールキャラ化／無表情キャラ化／老け顔／子供っぽすぎる顔／筋肉質／ガタイを良くする／長髪／髪色変更／制服変更／眼鏡／サングラス／帽子／バイク装備／スーツ姿

### 【画風固定】

2Dアニメイラスト／ビジュアルノベル／ゲーム立ち絵風／セルルック／非写実。フォトリアル禁止。

### コピー機（固定）

**外観固定**：白色樹脂ボディ／高さ約125cm／幅約65cm／奥行約70cm／大型タッチパネル／排紙トレイ／コピーガラス／テンキー／カードリーダー／USBポート。一般客が普通に使える外観。
