## 朝いちばんのニュース

**第六次プローブが、誤読監査を初めて無傷で通過したまま統一首位を取りました**:
**id=33 青基盤ペニシリン革命(81.6)**。核はペニシリン×4の革命2全バウンス
(盾2以下で発動するカムバック構造)で、条件モデル化の直後の探索が条件カードを
核とする首位を見つけた——表現力が増えるほど探索は本物の構造を燃料にする、
という夜の結論を象徴する結果です。百鬼夜行(80.0)は2位に。id=33は
メタプールへ昇格済み(11デッキ体制)。
プローブ剥落系列: −10.7 → −1.8 → −8.5 → −20.1 → −3.6 → **+0.2(収束)**。

その後の追試: 首位シェルの最適化は頭打ち(変奏78.3 vs 本家78.6)、
11デッキ体制での新規プローブは52.2/64.1と首位に遠く、環境は
**ペニシリン革命一強**で夜を終えた。「革命2全バウンスへの回答」が
次の探索の宿題(候補: 速攻ワンショット/墓地再展開/呪文主体)。
「墓地再展開なら回答になる」仮説は直接対決の実測で棄却済み
(邪眼転生11.8%/ターボゲート11.2%/戒王リアニ21.5%——全バウンスは部品を
墓地でなく手札へ戻すためMRC網に乗らない)。回答探索の最終結果: R4系統の進化(id=37)が対ペニシリン44%で最前線
(他は11〜36%)。勝ち越す回答は未発見のまま夜を終えた。
詳細は docs/loop_research.md 第二十二〜二十三弾。

## TL;DR

1. **誤読健診を6波まで実施し、誤読類型カタログは12種に**。探索器が高スコアを出す
   たびに監査→新類型発見→修正、のループを夜通し回した。新規探索の生スコアは
   73.6→68.1→58.7と下がり続けており、「誤読が探索の燃料だった」ことが定量的に見えた。
2. **【ターボゲート】を自律再発見**(ヴォジャワ→インフェルノ・ゲート→ギュウジン丸、
   成立率34.7%)。コンボ発掘の歴史的収束がまた一つ。ただしデッキとしての強さは
   誠実な物理では45.0(Tier上位ではない=本家の歴史と整合)。
3. **第四のループファミリー「自壊シナジー型(不死)」を実装し、学校男+ドゥリケン/
   シモーヌ・ペトル/ヘモグロの「無料の生贄」を自動検出・動的証明**(デスザーク期の
   実在テクの再発見)。自己再生はname_self/own_turn_onlyの新パラメータでexact表現。
4. **百鬼夜行(ハイランダー)は6.4pt剥落してなお首位(79.6)**。多様性プレミアムは
   +6.7→+1.7に縮小したが消えず。「多様性=誤読リスクの分散」という新解釈を得た。
5. race列は0/5,178件で外部データなしには埋められないと確定。種族はテキストの
   種族トークン検出で「変換見送り」(過小評価側)に倒す方針を実装した。

## 機能追加

- `summon_from_grave`/`summon_from_mana`: `name_self`(同名のみ)・`own_turn_only`
  (自ターン限定)・`civilizations`(マナ側)。`destroy_creature`: `max_cost`。
- exactキュレーション+7枚=計28名(ゲート/トリプル・リバイブ/レヴィヤ・ターン/
  冥王の牙/ドゥリケン/シモーヌ・ペトル/ヘモグロ)。
- loop-findに「自壊シナジー型(不死)」検証器(verify_immortal_candidate)。
- ツインパクトは【LINE】で前半面のみ変換(後半面は面選択未対応のため省略)。

## 残課題(優先順)

1. 探索→監査→修正ループの継続(誤読在庫はまだ尽きていない。特に「条件付き発動」系)
2. ツインパクト面選択のカーネル実装(面別コストのデータ整備が前提)
3. 無月の門・ガチンコ・ジャッジ等の条件付き誘発のモデル化
4. race列の外部データ取得(できれば種族フィルタ解禁=連ドラ等の精密再現)
5. validate-ratings(実戦ログとの相関検証、データ待ち)

## 追補(深夜帯の第十九〜二十弾)

- **「数えられる条件」のモデル化**: マナ武装・墓地枚数・革命・タップ状態の
  4+1種をconditionキーとして実装(実行器+goldfish)。29件のapproxが条件付きになり
  無条件発動の過大評価を解消。ウラミハデスが条件モデル化初のexactに(計29名)
- **文脈条件 source_tapped**: クラッシュ覇道の「攻撃タップ→B・A・D自壊→追加ターン」
  という本家実在のエンジンが正確に動くようになった(アンタップ除去では不発)
- combo-mineが新二段チェーンを発見: シモーヌ・ペトル→戒王の封→ウラミハデス→
  世紀末ヘヴィ・デス・メタル(成立率20%)。表現力拡張→コンボ空間拡張の実例
- 第五次プローブ(id=32 赤緑覇道ミッドレンジ): 発見時68.7→正確化後65.1。
  覇道エンジンは本物としてTier 2に定着
- 誤読類型は15種に(進化元蘇生/節跨ぎマナ送り/タップ条件の欠落を追加)
