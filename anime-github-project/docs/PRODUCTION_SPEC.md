# 映像・字幕仕様 固定設定

> **【固定】** YouTube用本編動画の出力仕様と字幕・タイポグラフィを全話で統一する。レンダラ：`anime-github-project/tools/build_episode_video.py`。

## 映像仕様

- アスペクト：**縦9:16**／解像度 **1080×1920**／**30fps**／H.264＋AAC、mp4。
- 構成：**タイトルカード3秒** → 本編 → **エンドカード4秒**。
- 上部に「**第N話　タイトル**」バッジを常時表示。下端に**進行プログレスバー**（緑）。
- BGMなし（環境音中心、SF時のみ第十三レジ起動音）。

## 字幕・タイポグラフィ（全カット固定）

- フォント：**Yu Gothic**。
- **本文（セリフ）**：56px、色＝アイボリー **#F1E8D2**、黒縁取り3px。**下三分の一の対話ボックス内**（枠：x40 / y1440 / 幅1000 / 高さ330）。
- **話者ラベル**：本文の上に小さく、40px、**緑 #A6C178・太字**。書式は「話者名＋改行＋本文」。
- **タイトルカード**：64px。シリーズ名「深夜二時の第十三レジ」（緑）＋「第N話」（大）＋話タイトル。
- 色設計：**アイボリー本文＋緑アクセント＋黒縁**。**下30〜40％は字幕セーフエリア**として人物・重要情報を置かない。
- 長いセリフは**自動でフォント縮小**してボックス内に収める（はみ出し禁止）。
- 字幕中間ファイル（`*_subs.ass`）はレンダー時の生成物（gitignore）。

| アクセント（話者名・枠・バー） | セージグリーン #A6C178 | `&H0078C1A6&` |
