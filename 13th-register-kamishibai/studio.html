🎬 Episode Studio ｜ 深夜二時の第十三レジ

セリフ・画像・音声をここで編集して、紙芝居プレイヤーへ直接公開します。

GitHub 接続

ここに保存した内容はブラウザの localStorage のみに残ります（サーバーには送られません）。 Personal Access Token は Contents: Read and write 権限だけで作成してください。

話数を選ぶ

AivisSpeech（音声合成エンジン）

音声生成は PCのブラウザ でこのページを開き、AivisSpeechエンジンをローカルで起動してください。 起動時にCORSを許可する必要があります（下の起動コマンド例を参照）。スマホではセリフ・画像・タイミングの編集のみ行えます。

起動コマンド例（AivisSpeech同梱エンジンの場合）：
run.exe --cors_policy_mode all

ログ

CSVで一括アップロード

列: speaker,dialogue,reading,pause_ms,cut（cutは1〜20の画像カット番号。reading省略時はdialogueをそのまま読み上げに使用）

セリフ一覧

画像カット（20枚固定）

codexなど外部の画像生成に渡す保存先パスです。ここに書き出したファイル名で置けば、そのまま反映されます。 タイミングは空欄なら自動（セリフ音声の長さから算出）、数値を入れると秒指定で固定できます。
