## 基本情報

- キャラID：`truck_driver_ep04`
- **50代後半**の長距離トラック運転手。
- **第4話の一見客**（常連ではない）。深夜に**唐揚げ棒**を買いに来る。

## 外見（固定）

- **恰幅のよい大柄でがっしりした体型。**
- **白髪まじりの短い角刈り**（刈り上げ気味）。
- **日焼けした赤ら顔の丸顔**、**太い眉**。
- **眠そうだが人の好い穏やかな表情。**
- 口ひげは無く、顎に短い無精髭程度。

## 服装・持ち物（固定）

- **濃紺〜グレーの作業つなぎ（ワークジャンプスーツ）。**
- **首にタオル。**
- **帽子はかぶらない**（帽子の有無をカットで変えない）。
- 持ち物：唐揚げ棒／トラックのキー／作業手袋／水筒または缶コーヒー／首のタオル。

## 性格（固定）

疲れているが悪人ではない／常連ではなく一見客／**怒りより懐かしさが勝つ**。

## 変更禁止

- **座木山辰哉に似せない**（痩せ型・乱れた黒髪・口ひげ・下唇の突き出し・釣りベスト・釣り具にしない。別の顔と体型にする）。
- 汗田竜司のスポーツサングラス・バイクジャケットにしない。
- 未来青年のような疲弊した若い会社員にしない。
- スーツ・店舗制服にしない／配送制服化しない。
- 若者化／別人化／未来人化。
