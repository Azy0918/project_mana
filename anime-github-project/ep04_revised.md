タクミ：未了で運用しないでください。
エリ：仮運用。
タクミ：仮で時空扱わないでください。
ナレーション：ノートの最後のページには、誰かが急いで書き残したようなメモと、未来を予告するかのような紙片が挟まれている。「時間は袋分けできる場合あり。ただし袋代あり」「2時28分。唐揚げ棒を買った客が怒る」と、妙に具体的な記述が並んでいる。妙に具体的すぎて逆に信じたくない。
タクミ：意味がわからない。
エリ：でも当たる。
タクミ：それが怖い。
タクミ：あと23分で役に立つんですよね。
エリ：よかったね。
タクミ：よくないです。
ナレーション：ホットスナックケースの中には、1本だけ残された唐揚げ棒がある。油の香りがわずかに漂い、時間の経過を感じさせる。なんとなく「主役です」と言いたげな佇まいだ。
タクミ：あれが怒られるやつですか。
エリ：たぶん。
ナレーション：ケースの小さな旗がかすかに揺れ、その裏には「まだ怒られていません」と書かれている。未来に対する予防線のようだ。妙に前向きである。
タクミ：予防線張ってる。
ナレーション：午前2時17分。何の前触れもなく、第十三レジが静かに現れる。空気の密度が変わったように感じられる。ちょっとだけ「来ちゃったか」という空気になる。
第十三レジ：未来クレーム予告を確認。
タクミ：確認しないでほしい。
第十三レジ：未来レシートを先行印字。

タクミ：お詫びが会計に入ってる。
第十三レジ：発行するとクレーム確定。
タクミ：じゃあ出さないで。
第十三レジ：先に謝る仕様です。
タクミ：迷惑です。
ナレーション：自動ドアが静かに開き、外の夜気とともに汗田竜司が入ってくる。落ち着いた足取りだが、状況を見透かしているようでもある。だいたいこういう時に来る人だ。

タクミ：言い方。
汗田竜司：原因は謝罪不足じゃない。温度のズレだ。
タクミ：記憶の温度？

タクミ：未照合で謝ったんですか。

エリ：唐揚げ棒。
ナレーション：スキャナーが短く鳴る。ピッという音が静かな店内に響く。やけに頼もしい音だ。

タクミ：普通ですね。
