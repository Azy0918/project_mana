# ナビの取り付け固定設定（追加）

> **【固定】** ナビは汗田が運転中に見るための機器。シリーズ全話で取り付け方法を固定する。

## 取り付け位置

- CB200Xの**ハンドル中央、メーターパネルの少し上**。
- RAMマウント風のボールジョイントで固定。

## 向き（最重要）

- **画面は必ず汗田（ライダー）の方向を向く。** ライダーが自然に見える角度。
- **カメラへ正面を向けない。客側へ向けない。**

## 画面角度

- 上方向へ約25°
- ライダー側へ約20°

## カメラから見える画面

- **通常**：画面は斜めに見える程度。真正面は見えない。
- **正面から撮る場合**：カメラには主に「ベゼル／本体側面」が見える。画面は少ししか見えない。
- **汗田視点のときだけ**：画面全体が見える。

## 画面を見せたい場合（AI画像生成ルール）

- 画面内容を見せたい場合でも、**ナビ本体は回転させない**。
- カメラを **汗田の肩越し（Over-the-Shoulder）** へ移動する。

## 推奨カメラ構図

## 禁止事項（絶対禁止）

ナビをカメラへ向ける／ナビを180°回転する／観客向きにする／バイク外側へ向ける／ハンドルから外す／浮かせる／左右逆に付ける

## カメラ優先順位

**現実の取り付け位置 ＞ 画面の見やすさ。** 画面を見せるためにナビの向きを変えない。必要ならカメラを動かす。

## 画像生成用の一文（毎回追加推奨）

> The motorcycle navigation unit is permanently mounted on the handlebar and always faces the rider. Never rotate the screen toward the camera. If the display must be visible, move the camera to an over-the-shoulder view instead of changing the navigation unit's orientation.
