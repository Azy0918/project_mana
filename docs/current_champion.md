## 勝ち筋(機構)

1. **攻撃を罰する除去S・トリガー**: シールドが割られるたびに除去が無償で起動。
   - 戒王の封: 相手2体破壊+自墓地から闇クリーチャー蘇生(スーパーS・トリガー)
   - 地獄門デス・ゲート: 相手1体破壊+蘇生
   - 魂穿ツ煌世ノ正裁Z: 相手1体除去
   - 炸裂の影デス・サークル / ザ・美食秘宝サイキック・イーター: 生け贄除去
2. **攻撃を凍結**: DNA・スパーク(S・T)が相手全クリーチャーをタップ。
3. **受けの自己強化**: DNA・スパークは全タップに加え**シールドを1枚追加**し、
   S・トリガーの母数を増やす正のループ。
4. **除去しながら盤面維持**: 戒王/地獄門の蘇生で、除去後も自軍が立ち続ける。

## なぜ無敵か(検証済み)

- **7角度の反証すべて退ける**: 火アグロ29% / 火S-trig35% / シールド焼却18% /
  水ミル11.6% / 全文明無制限11.6% / 自然マナ送り3.4% / 水闇要塞11.8%。
- **色固有**: 闇の蘇生核+光の全タップ/シールド増殖の組合せは光闇のみ。
  水闇移植は54.4%止まり。
- **ポリシー非依存**: 挑戦者にS・トリガー警戒(突撃抑制)を与えても勝率は
  むしろ悪化(-0.3〜-2.3pt)。要塞は受けの誘発でなくバリューで勝つ。
- **過大評価の産物でない**: 是正76件後も支配的。壁(パーフェクト・ギャラクシー
  不採用)に依存せず、純粋に除去+蘇生+全タップのエンジンで勝つ。
