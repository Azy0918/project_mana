## コンセプト

- **過去を処理するレジ。** 第十三レジが「今」を処理するのに対し、第十二レジは「過去」へ引っ張る。
- 店舗の常設レジではなく、第11話に現れる対比装置（第十三レジと同様、カウンター上に出現するイメージ）。

## 外観（固定・設定シート `twelfth_register_sheet.png` 準拠）

- **昭和の商店にありそうな古いレジ端末。** **木目調**、または**くすんだベージュ**。
- **丸みのある筐体**、**古い金属キー**、**紙伝票の差し込み口**、**琥珀色の小さな表示ランプ**。
- 派手にしない。店内に置いてもおかしくない「古い道具」感。卓上〜小型サイズ（巨大装置にしない）。
- 黒い第十三レジ（卓上POS）とは**別機体**。

## 役割・思想（固定）

- **過去処理を優先。**
- 昭和伝票／過去の商品／未処理の回収を連想させる。
- 第十二と第十四は**思想が強い**（過去・未来へ引っ張る）。第十三は無機質。

## レシート／出力（固定）

- 古い感熱紙やドットプリンタ風の、**過去の伝票・古い記録**を出力する。

## 禁止事項

現代の黒いPOS化／未来デザイン／透明化（それは第十四レジ）／巨大装置／ホログラム／ネオン／ロボットアーム／派手なSF演出。

## 音声

- 声＝**未定**（出演時に確定）。方向性は古めかしく重い、過去を語る無機質。

## 【最重要】

第十二レジは**古い木目調・過去処理**で固定。第十三レジ（無機質・今）／第十四レジ（透明・未来）との対比を必ず維持し、別デザインに描き直さないこと。
