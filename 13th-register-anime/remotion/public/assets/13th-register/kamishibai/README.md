# Kamishibai Image Assets

Place generated realistic still illustrations here.

Expected filenames:

- `pv_001.jpg`
- `pv_002.jpg`
- ...
- `pv_036.jpg`

The Remotion composition `KamishibaiRealPV` reads these files automatically. If a cut image is missing, the composition shows a storyboard placeholder instead.

Source prompt list:

- `tools/kamishibai_real_cut_prompts.csv`
