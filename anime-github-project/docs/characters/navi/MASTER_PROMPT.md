## 基本情報

- **名称**：未来食品流通対応ナビ（通称：ナビ）
- **所有者**：汗田竜司
- **役割**：
  - 普段は普通のバイクナビ
  - 午前2時17分になると未来食品流通管理システムへ接続する
  - 第十三レジとの通信端末
  - 未来物流データ・配送記録・異常地点を表示する
