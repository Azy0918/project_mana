## コンセプト

- **未来を処理するレジ。** 第十三レジが「今」を処理するのに対し、第十四レジは「未来」へ引っ張る。
- 店舗の常設レジではなく、第11話に現れる対比装置。

## 外観（固定・設定シート `fourteenth_register_sheet.png` 準拠）

- **透明アクリル／ガラスのような筐体。** 内部が透けて見える。
- **白と淡い紫の光**。**薄い浮遊パネル風の表示**。**直線的で清潔すぎる未来端末**。
- 未来的だが、店内で浮かない範囲（派手なホログラム乱舞はしない）。卓上〜小型サイズ（巨大装置にしない）。
- 黒い第十三レジ、古い第十二レジとは**別機体**。

## 役割・思想（固定）

- **未来処理を優先。**
- **確定／予測／返送**を迫る。
- 第十二と第十四は**思想が強い**。第十三は無機質。

## UI／出力（固定）

- 透明画面に未来UI（確定・予測・返送）。文字は細い角ゴシック、**白と淡い紫**基調。
- 出力は未来の通知・予測レシート。

## 禁止事項

現代の黒いPOS化／木目調化（それは第十二レジ）／巨大装置／過剰なホログラム／ネオン／ロボットアーム／派手すぎるSF。

## 音声

- 声＝**未定**（出演時に確定）。方向性は澄んだ、断定的で事務的な無機質。

## 【最重要】

第十四レジは**透明な未来型・未来処理**で固定。第十二レジ（木目・過去）／第十三レジ（無機質・今）との対比を必ず維持し、別デザインに描き直さないこと。
