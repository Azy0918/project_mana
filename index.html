Overview

カードは「データ」ではなく、イベントに反応する能力の集合

本エンジンは、デュエル・マスターズ プレイスの対戦を Python の標準ライブラリのみで再現する イベント駆動・拡張可能なルールエンジン。エンジンが瞬間ごとにイベントを 発火し、カード側が反応する設計で、新カードは本体に触れず部品を1つ足すだけで増える。 bot に操作させて勝率を測り、未知デッキを探索するための土台になっている。

探索エンジン

Exploration

未開拓デッキ探索:メタを超えるデッキは見つからなかった

MAP-Elites で戦略ニッチを発掘(Heuristic で高速探索)し、各ニッチの代表を ISMCTS で忠実評価した。 結果は明快 ―― どのニッチも忠実評価では勝率 0.5 に届かない。 さらに重要なのは、Heuristic が高く評価したデッキほど ISMCTS で大きく崩壊した点だ。

⚠ 評価器が生む "幻のアグロ"

じゃんけん構造のメタ

多様性 > 単一目的

最も粘ったのは Heuristic に過小評価されがちな受け/ロック系コントロール。 単一目的GAはアグロの幻に一直線に収束するため、QD の多様性が逆に「忠実評価で強い軸」を 取りこぼさず残した。

読み方

これらは 単一目的でなく多様性で探索した生の個体。枚数の偏り(1枚挿し)は 未調整の証拠であり、ここから人間が4枚化・不純物除去で磨くのが次の工程。★=効果実装済みカード。

Debugging

探索が炙り出した無限ループバグ

AD全体プールでの探索が、ある対戦で 8時間以上ハングした。原因は カード単体ではなく 2枚の相互作用だった ―― 水「次元の嵐 スコーラー」と 水「異端流し オニカマス」。

  1. ① 異常検知出力が更新されないまま CPU が回り続ける。ターン跨ぎの上限 (max_turns)はターン内ループを止められない、と判明。
  2. ② ファズで再現色コヒーレントなランダムデッキを 114,268個 対戦させ、ターン内行動数を監視。暴走を2件捕捉 ―― いずれも犯人は1ターンに 約796回召喚される「次元の嵐 スコーラー」。
  3. ③ 機構の特定スコーラーは「呪文5枚で無料召喚(G・ゼロ)」。 無料召喚するたびに相手のオニカマスが手札へ戻すが、コストを払っていない ため条件は維持され、AI が永遠に出し続ける。実機トレースで状態が完全な固定点になることを確認。
  4. ④ 修正個別: 踏み倒しメタで戻された札は同ターン 再度踏み倒せないよう刻印。汎用: 1ターンの行動数に安全弁を追加し、 未知の無進行ループも強制終了。
  5. ⑤ 検証全211テスト合格・ 27,753戦で暴走0(以前暴走した同一デッキ列を含む)。AD全体探索も 512秒で完走するようになった。

✅ 教訓

カードバグというよりエンジンの構造的欠陥(無進行の無料プレイを無制限に 再提示する)だった。広いプールを機械的に総当たりすることが、人手のテストでは踏まない エッジケースを掘り当てる ―― 探索そのものが検証になる。

Conclusion

結論:メタは頑健、未踏の種は「受け/ロック」

ND探索(0.425)・AD全体探索(0.400)・ISMCTSループ内の二段GA(忠実0.283)の3方向すべてで、 実装カバレッジ内では現環境メタを支配するデッキは存在しないことが再確認された。 メタは頑健で、相性はじゃんけん構造を持つ。

一方で、忠実評価で最も粘るのは Heuristic が見落とす受け/ロック系コントロール。 ここが今後の「未開拓の種」として最有望だ。次の一手は明確 ―― この軸をシードに、ISMCTS をループ内に入れた二段GA で磨くこと (1手読みの幻を排した、最も忠実な探索)。

方法論の核

「未知シナジー → 状態変換連鎖 → 勝利条件到達 → 環境への有効性」。 強さの主張は必ず忠実評価器で裏を取る。速い評価器の高評価は、まず疑う。
