# 第十三レジ ｜ 固定設定（画像生成用マスタープロンプト）

> **【デザイン修正・最新版】** この設定はシリーズ全話で固定する。
> 第十三レジは「未来の巨大装置」ではなく、現代のコンビニに突然現れる **13番目のPOSレジ（卓上サイズ）**。
> 一見すると新型レジにしか見えないが、未来・過去・宇宙・並行世界の物流情報を処理する。
> **見た目は極力コンビニに溶け込ませる。SF感は控えめ。**
> ただし**前面のネオンシアンの目二本＋水平の口の「顔」は必須・固定**（→「顔（必須・固定）」節）。

---

## コンセプト

- 第十三レジ＝「13番目のPOSレジ」。巨大装置・壁一面の機械ではない。
- 一見ただの新型レジ。視聴者が一瞬「あ、新しいレジかな？」と思う程度が理想。
- **見た目は普通、機能（処理内容）だけが異常。**
- 未来技術を見せる作品ではなく、コンビニの日常に未来物流が紛れ込む作品。

## サイズ（卓上サイズ）

カウンター上に置ける卓上サイズ。一般的なPOSレジより少し大きい程度。**大型装置にしない。**

- 幅：約35cm
- 奥行：約45cm
- 高さ：約55cm

## 設置場所

- **レジカウンター右端、第12レジの右隣**（毎回同じ位置に固定）。コピー機方向のカウンター端。
- **午前2時17分だけ**現れ、2時20分に消える。
- カウンターから生えているような巨大設備にしない。**既存レジと並ぶ一台**として配置する。
- 出現位置・演出・カメラ構図・キャラ立ち位置の固定 → [`../../settings/store_interior/REGISTER13_APPEARANCE.md`](../../settings/store_interior/REGISTER13_APPEARANCE.md)、店内全体 → [`../../settings/store_interior/FLOOR_PLAN.md`](../../settings/store_interior/FLOOR_PLAN.md)

## デザイン

- 全体色：艶消しブラック／濃いチャコールグレー
- アクセント：青白い細いLEDライン
- 未来的だが派手すぎない。**店内で浮かないことを最優先。**

## ディスプレイ

- 15インチ程度。
- 通常は黒画面。
- 起動すると「第十三レジ」「営業開始」「02:17」程度だけ表示。
- **演出用の派手なホログラムは禁止。**

## 操作部

- 通常のPOSに近い：バーコードリーダー／小型ディスプレイ／レシートプリンター。
- テンキーは無くてもよい。タッチパネル主体。

## レシートプリンター

- 普通の感熱紙（未来らしい紙にはしない）。
- **印字内容だけが異常。** 例：
  - 危険知識封印　1件
  - 未来大戦争　発生保留
  - 店長確認　未了
  - 本日の営業　継続中

## 発光

- 通常はほぼ光らない。
- 処理中だけ、青白いラインが静かに流れる。
- **ゲーム機のような発光は禁止。**

## サウンドイメージ

- 通常POSより少し高級感のある電子音。
- **派手なSF効果音は禁止。**（参考：別途制作の起動音 `assets/sfx/register13_start.wav`）

## 世界観

- 重要なのは「普通のレジなのに処理内容だけ異常」というギャップ。

## NG（禁止）

巨大装置／壁一面の機械／床から生える装置／SF映画の制御卓／大量のホログラム／ネオン発光／メカメカしい配線／ロボットアーム

## OK（目指す方向）

最新型セルフレジ程度の未来感／現実のPOSレジの延長線／コンビニ店員が普通に操作できそう／見た目は普通・機能だけが異常

## 顔（必須・固定）

第十三レジには **顔が必須**。本体は普通の卓上POSレジに見せつつ、前面（ディスプレイ／パネル面）に次の最小限の発光フェイスを必ず持たせる。

- **ネオンシアンの短い水平な目が二本**
- **小さな水平の口が一つ**
- 無表情・眠そう・機械的。でも妙に意思がある。

扱い：

- 顔は「キャラの記号」として**全カットで同一形状に固定**（目二本＋口一つ、配置・形・比率を変えない）。
- 普段はごく控えめな発光、処理中は少しはっきり点灯する程度。**大きな漫画的フェイスにはしない**（あくまで小さな発光パネル上の最小限の目・口）。
- かわいくしすぎない。人間ではなく業務端末として少し不気味。

## 旧設定からの変更点（重要）

- **変更（縮小）**：本体を「黒く重い大型筐体／角ばった金属とガラス」→ **卓上サイズの新型POSレジ調**へ縮小し、店内に溶け込ませる。巨大装置・壁一面の機械はNG。
- **維持**：ネオンシアンの**目二本＋水平の口の「顔」は必須として継続**（上記「顔（必須・固定）」）。
- 各話 `scene_manifest*.json` の `imagePrompt`（全カットに「黒く重いセルフレジ端末…顔つき…」を内包）と既存生成画像は**旧の大型筐体のまま**。新デザイン反映には、本体描写の書き換え（**顔つきは維持**・筐体を卓上POS化）と画像再生成が必要。
