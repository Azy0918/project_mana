# 研究知見: ヒューリスティック評価と厳密シミュレーションの乖離 (2026-06)

進化探索→厳密レーティングのループ(`evolve-rate`)を3つの重みプリセットで実行した結果。
games=100/seed=11/combo方策。

## 主要な発見

**ヒューリスティック適応度が最高のデッキが、厳密シミュレーションでは最弱クラスだった。**

| 候補 | ヒューリスティック適応度 | 厳密強さスコア(対メタ平均勝率×100) |
|---|---|---|
| 強さ重視 best_overall | 41.15 | **17.8** |
| 強さ重視 best_novelty | 40.45 | **45.8** |
| メタ適性重視 best_overall | 36.05 | 20.8 |
| メタ適性重視 best_novelty | 34.85 | 45.8 |
| バランス best_overall | 40.2 | 34.8 |

ヒューリスティック(タグ・カーブ・文明バランス)は「形の整ったデッキ」を最高評価するが、
実対戦では効果の質と速度が支配的で、評価が逆転する。**候補選別をヒューリスティック
のみで行うと、本当に強い候補を捨てている可能性が高い。**

### 示唆

1. 進化探索の選別関数に厳密レーティングを組み込む価値が大きい
   (`apply_sim_strength` の比重0.3は控えめすぎる可能性。実戦データでの回帰が待たれる)。
2. `evolve-rate` を探索の最終段だけでなく世代内選別に使う「ハイブリッド探索」が次の一手
   (計算コスト: 1候補100試合 ≈ 0.1秒なので世代14体×10世代でも約2分)。

## カバレッジ進捗

- 承認済みEffectScript: 21.4% → **32.3%**(1,670/5,178枚)
- 進化探索の上位デッキで使われていた未承認カードの分析から、進化ハイフン表記・侵略行・
  墓地条件G・ゼロ・「見て墓地に置く」・マナ回収(`mana_to_hand` op)等を追加対応。
- 残る未承認はゴッド・超次元・ガチンコ・ジャッジ等の大型メカニズムが中心。

## 再現コマンド

```bash
python -m src.battle.research --games 100 --seed 11 --policy combo \
  evolve-rate --generations 10 --population 14 --focus 強さ重視
```
