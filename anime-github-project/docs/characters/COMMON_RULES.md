# キャラクター共通固定ルール

> 全キャラクターに共通して適用する固定ルール。各キャラの `MASTER_PROMPT.md` はこれを前提とする。

- 全キャラクターは作品**全12話を通して同一人物**である。
- **顔・輪郭・髪型・髪色・目・鼻・口・体格・身長・服装・持ち物・年齢感・雰囲気**を必ず固定する。
- **別人として描き直さないこと。**
- 変更してよいのは **表情・視線・ポーズ・腕や手の動き** のみ。
- 画風は **2Dアニメイラスト／セルルック／ビジュアルノベル風**で統一。**フォトリアル禁止。**
- キャラクターデザインはシリーズ全体を通して完全に維持すること。
