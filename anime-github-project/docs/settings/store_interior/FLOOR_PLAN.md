## 固定ルール

- 第13レジはカウンター上。
- 12番レジの右隣。
- コピー機は雑誌棚の横。
- 冷凍庫はバックヤード。
- おにぎり棚は入口近く。
- ホットスナックとコーヒーマシンはレジ横。
- **第13レジの出現位置（第12レジ右隣のカウンター天板）には、薄いグレーの四角いタイル（マーカー）が常にある**（2:17にその真上へ第13レジが出現／消滅後はタイルだけ残る）。固定要素。
- **毎話この配置を変えない。**

- **第13レジ**：レジカウンター右端（→ [`REGISTER13_APPEARANCE.md`](REGISTER13_APPEARANCE.md)）

- **冷凍庫**：バックヤード＝第3話「昨日バニラ」の舞台。
- **おにぎり棚**：入口近く＝タクミが毎回見る場所。
