# 厳密シミュレーション研究ノート

シミュレーション基盤の現状・既知の近似・再現手順を記録する。
(ロードマップ本体は `docs/roadmap_v2_simulation.md`)

## 再現手順

```bash
# 1. EffectScript整備(下書き生成 → 再生成 → 完全変換ぶん一括承認 → キュレーション適用)
python -m src.battle.research prepare-effects

# 2. メタ総当たり戦
python -m src.battle.research --games 100 --seed 5 meta-tournament
```

## EffectScript整備の3層構造

1. **自動下書き** (`draft_generator.py`): 正規表現でテキストから命令を抽出。
   注釈括弧・カーネルキーワード行・構造トークン(【LINE】等)を変換済み扱いにする。
2. **一括承認** (`approve_clean_drafts`): テキストを完全変換できた下書きのみ自動承認。
   部分変換はdraftのまま残しレビュー対象とする。
3. **キュレーション** (`data/effect_scripts/curated_meta.json`): 自動変換できない複雑カードへの
   人手/AIによる近似定義。カード名キーで、`prepare-effects` のたびに承認済みとして上書き適用される。
   **複雑カードの効果を追加するときはこのファイルに追記するのが最短経路。**

現状: 全5178カード中、承認済み1670(32.3%)。収集済みメタデッキ5種のカードは
ほぼ100%承認済み(自然単のみ18/20)。

## 既知の近似・制約(評価時に留意)

- **対応済みメカニズム(追加)**: G・ゼロ、追加ターン(`extra_turn` op、1プレイヤー3回まで)、
  コスト軽減(常時オーラ近似)、B・A・D(常に軽減を使用+ターン終了時破壊)、
  サバキZ(S・トリガー相当の近似)、チャージャー(解決後マナへ)、スレイヤー、
  パワード・ブレイカー(パワー6000につき1枚)、進化(召喚酔いなし・進化元条件は無視)、
  タップイン、シールド焼却(手札に加えさせず墓地へ)。
- **近似変換(自動下書き)**: サーチ系「手札に加える」→ドロー、パワー低下→同値以下破壊、
  自己破壊コスト→destroy(scope self)、手札捨て/シールド回収/手札マナ置きは専用op。
  山札シャッフル・「ただし〜」等の無害な注釈は変換済み扱い。
- **未対応メカニズム**: 超次元、特殊勝利、コスト増加、置換効果、パワー修正、「選ばれない」。該当カードはキュレーションで縮小近似 or バニラ扱い
  (curated_meta.json の note に明記)。
- **コンボ方策(`--policy combo`)**: 手札にG・ゼロカードがあるとき、安い呪文から連打して
  条件達成→0コスト召喚するプレイラインを取る(`ComboPolicy`)。G・ゼロカードはチャージに
  埋めない。これにより水単スコーラーは 18.8% → 33.0%(combo方策時)。
  コンボデッキを含む評価では `--policy combo` を推奨。まだ過小評価の余地はある
  (追加ターン後の詰め筋などは未最適化)。
- **選択・条件付き効果**: 「次のうちいずれか」「そうした場合」は固定モードで近似。
- **対象選択ヒューリスティック**: 効果の対象は最大パワー優先。方策による選択はv2.0残課題。
- **ツインパクト**: パワーを持てばクリーチャー面で運用(呪文面は片面のみ反映)。
  コスト0登録のカードはパワーからコストを推定(下限2)して無償プレイを防止。
- **方策**: 既定は貪欲。`LookaheadPolicy`(攻撃の1手読み+determinization)は
  現メタミラーで貪欲と同等(51%)。ブロッカー・受け効果が増えるほど有利になる見込み。

## 探索→検証ループと相関検証

- `python -m src.battle.research evolve-rate --generations 8 --population 12`:
  進化探索の上位候補(best_overall/novelty/meta)を自動でメタ総当たり判定に流す。
  「探索はヒューリスティック、検証は厳密シミュレーション」のループが1コマンドで回る。
- `python -m src.battle.research validate-ratings`: 実戦ログ(real_match_logs)の
  デッキ別実勝率とsim_ratingsのシミュレーション勝率のPearson相関を算出。
  実戦5試合以上のデッキが3件貯まると有効(現状はデータ不足を案内して終了)。
- `python -m src.battle.research --games 300 sanity-check`: **実戦ログなしで使える妥当性検証**。
  「速攻は鈍重に勝つ」「トリガー除去は同型バニラに勝ち越す」「ミラーは五分」等の
  方向性チェック6件(交絡を避けた同一ステータス比較)。カーネル・方策を変更したら
  必ず実行する。テストスイートにも組み込み済み(tests/test_sanity.py)。
