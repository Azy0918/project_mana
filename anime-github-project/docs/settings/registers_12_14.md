# 第十二レジ／第十四レジ 固定設定（EP11対比装置）

> **【固定】** 第11話「第十二レジと第十四レジ」に登場する**対比装置**。第十三レジと並ぶ存在として、見た目と思想を固定する。
> 第十三レジ本体 → [`../characters/register13/MASTER_PROMPT.md`](../characters/register13/MASTER_PROMPT.md)

## 第十二レジ（過去）

- **古い木目調のレジ。**
- **過去処理**を優先する。
- 昭和伝票／過去の商品／未処理の回収を連想させる。

## 第十四レジ（未来）

- **透明な未来型レジ。**
- **未来処理**を優先する。
- 確定／予測／返送を迫る。

## 第十三レジとの違い

- 第十二と第十四は**思想が強い**（過去／未来へ引っ張る）。
- 第十三は**無機質**だが、「**今この店にあるもの**」を処理する。

## ⚠ 命名の注意（要整理）

- 店舗の**通常営業レジ**「**第12レジ**（現代の黒いPOS・第十三レジが右隣に出現）」と、本書の**第十二レジ（古い木目調の対比装置）**は**別物**。
- 数字の重複が紛らわしいため、EP11対比装置の方は本文中で「第十二レジ（木目）／第十四レジ（透明）」のように見た目を併記すると安全。必要なら別名・別表記を検討。
