# 第十三レジ 出現位置 固定設定

> **【固定】** 第十三レジは作品**全話を通して必ず同じ場所に出現**する。出現位置は変更しない。
> 本体デザインは [`../../characters/register13/MASTER_PROMPT.md`](../../characters/register13/MASTER_PROMPT.md)、店内全体は [`FLOOR_PLAN.md`](FLOOR_PLAN.md) を参照。

## 出現場所

- **レジカウンター右端。第12レジの右隣。**
- 通常時は何もない。
- 午前2時17分になると、音もなく一台分のスペースが現れ、そこに第13レジが出現する。

## 出現演出（毎回同じ）

- 蛍光灯が一瞬だけ瞬く
- 店内の電子音が止まる
- 第13レジだけが現れる
- 壁・床・カウンターは変化しない

**巨大なエフェクトは禁止。**

## 消滅

- 午前2時20分。レジだけ消える。跡は残らない。

## 周囲の設備（毎回固定）

- 左：第12レジ
- 右：カウンター端
- 後方：バックヤード入口
- 斜め左奥：コーヒーマシン
- 遠景：コピー機

## キャラクター位置

- **タクミ**：第12レジ担当。異常が起きると右を向く。
- **ミナ**：第13レジも普通に操作する。立ち位置は毎回ほぼ同じ。
- **汗田**：客側から第13レジを見る。必要に応じて店員側へ回る。
- **未来会社員**：第13レジの正面。普通の客と同じ位置。

## 出現条件

- 午前2時17分。毎回同じ。タイミングは変更しない。

## 禁止事項（絶対に変更しない）

床から生える／コピー機横に出現／雑誌棚前に出現／客席に出現／バックヤードに出現／店外に出現／浮遊する／巨大化する／毎回違う場所に出現する

## 【最重要】

第十三レジは「**第12レジの右隣**」にしか現れない。
視聴者が「あ、2時17分だからあそこに出る」と自然に分かることを目標とする。

## 推奨オプション（位置をさらに安定させる案・要採用判断）

画像生成AIで位置をより安定させるため、**視覚的な目印**を一つ足す案：

- カウンターのその位置だけ、床に**薄いグレーの四角いタイル**がある。
- 普段は誰も気にしないが、2時17分になるとその位置に第13レジがぴったり現れる。
- 消えると再びただの床（またはカウンターの空きスペース）に戻る。
